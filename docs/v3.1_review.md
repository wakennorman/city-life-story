## 二、v3.1 经济系统详细设计

### 2.1 多级累进财富税 (B4)

```
| 资产区间              | 日税率 | 年等效 | 难度乘数 (休闲/标准/困难) |
|---------------------|--------|--------|------------------------|
| ¥200,000 ~ ¥500,000 | 0.03%  | 10.95% | 0.7x / 1.0x / 1.4x    |
| ¥500,000 ~ ¥2M      | 0.05%  | 18.25% | 0.7x / 1.0x / 1.4x    |
| ¥2M ~ ¥10M          | 0.08%  | 29.20% | 0.7x / 1.0x / 1.4x    |
| ¥10M+               | 0.12%  | 43.80% | 0.7x / 1.0x / 1.4x    |
```

**设计原理：**

- 边际税率递增：高资产玩家承受更高比例税收，体现"能力越大责任越大"
- 累进计算而非全额税率：仅超出门槛部分按高税率，避免"跳档惩罚"
- 难度乘数：休闲减 30%，困难增 40%，保持难度区分度

### 2.2 动态村长债利率 (B2)

```
| 总资产阈值     | 日利率 | 年等效  | 设计意图           |
|-------------|--------|---------|------------------|
| < ¥100,000  | 0.20%  | 73%     | 新手友好          |
| ¥100,000+   | 0.30%  | 109.5%  | 鼓励继续积累       |
| ¥300,000+   | 0.40%  | 146%    | 中产激励          |
| ¥500,000+   | 0.55%  | 200.75% | 高利率吸引         |
| ¥1M+        | 0.75%  | 273.75% | 显著收益差异       |
| ¥3M+        | 1.00%  | 365%    | 老玩家有效激励     |
```

### 2.3 反膨胀机制 (B1)

**连续盈利衰减：**

```
连续盈利 0-3 次 → 收益系数 1.00 (无衰减)
连续盈利 4 次   → 收益系数 0.92 (衰减 8%)
连续盈利 5 次   → 收益系数 0.84 (衰减 16%)
连续盈利 6 次   → 收益系数 0.76 (衰减 24%)
连续盈利 7+ 次  → 收益系数 ≥ 0.50 (最大衰减 50%)
```

**市场饱和度惩罚：**

```
玩家资产 / 城市总财富 ≤ 阈值 → 惩罚系数 1.0
超过阈值后每 1% 额外比例 → 惩罚系数 -2%
(困难 15% / 标准 20% / 休闲 25%)
```

**日投资次数限制：**

```
股票交易上限: 5 次/日
房产交易上限: 2 次/日
```

### 3.2 关键发现

1. **难度梯度有效**：休闲 ¥273万 > 标准 ¥261万 > 困难 ¥223万，差距约 18%
2. **税收系统被充分验证**：100% 触发率，证明 ¥20万入门税门槛合理
3. **税收累进性验证**：困难模式总征税 ¥26.3亿 > 标准 ¥22.8亿 > 休闲 ¥16.6亿，难度税率乘数生效
4. **资产无极端膨胀**：P99 在 ¥340万 以内，未出现 ¥1亿+ 的极端情况
5. **破产率 0%**：模拟参数下经济系统具有稳定性（但实际游戏中破产应有意义）
6. **标准差合理**：约 ¥36~47万，反映合理的随机性但不失控
