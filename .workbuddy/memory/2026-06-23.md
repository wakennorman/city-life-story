## city-life-story P0 BUGFIX：renderTradeTab 崩溃修复

**执行人**：玩法师（游戏设计师）
**commit**：`6d90d36`

### Bug

`Uncaught TypeError: Assignment to constant variable at renderTradeTab`
玩家切到交易Tab就黑屏崩溃。

### 根因

`render.js:2631` 用 `const goodsList =` 声明，但 `render.js:2771` 又 `goodsList = SortUtils.sortInteractiveList(...)` 重新赋值，触发 const 不可重新赋值的 TypeError。

### 修复

`const goodsList` → `let goodsList`（1 行改动）

### 验证

- `node --check` 通过
- `python build.py` 成功（3588.1 KB）
- dist grep 确认 `let goodsList` + `goodsList = SortUtils` 都在

### 经验教训

这是经典的 const vs let 错误。代码审查时应注意：凡是用 const 声明的变量，下方任何位置都不能再赋值（包括 += / -= 等）。SortUtils.sortInteractiveList 返回新数组，所以需要重新赋值，应该用 let。
