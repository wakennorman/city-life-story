## 3. 代码组织结构分解

```
src/
├── main.py              # 入口，初始化 Pygame 并启动游戏循环
├── core/                # 基础实体、组件、事件总线
│   ├── __init__.py
│   ├── entity.py        # Entity 基类
│   ├── component.py     # Component 基类
│   ├── event_bus.py     # 事件发布/订阅
│   └── config_loader.py # 读取 JSON 配置文件
├── systems/             # ECS 系统
│   ├── __init__.py
│   ├── movement.py      # 移动系统（玩家和NPC）
│   ├── world_gen.py     # 地图生成（Perlin噪声+预置结构）
│   ├── economy.py       # 基础经济系统（金钱、资源）
│   └── time.py          # 时间循环（白天/夜晚）
└── ui/                  # 用户界面
    ├── __init__.py
    ├── renderer.py      # 摄像机、Tile渲染
    ├── hud.py           # HUD 显示（时间、金钱）
    └── event_handler.py # 键盘/鼠标事件处理
```

- `systems/` 中的每个系统都直接实例化 `core/` 中的 Entity，但 `component.py` 尚未被充分使用。
- `ui/renderer.py` 负责从 `systems/world_gen.py` 获取地图数据，耦合较紧。

## 4. 关键文件及其用途

| 文件 | 用途 |
|------|------|
| `main.py` | 游戏循环，初始化所有系统，处理帧更新 |
| `core/entity.py` | Entity 类，只包含 id 和组件列表 |
| `core/component.py` | Component 类，空基类，尚未具体实现 |
| `core/event_bus.py` | 事件总线，当前仅用于 UI 与 systems 通信 |
| `core/config_loader.py` | 读取 `config/` 下的 JSON（地图大小、npc数量等） |
| `systems/movement.py` | 处理玩家 WASD 移动、NPC 随机游走 |
| `systems/world_gen.py` | 生成50x50 tile地图，放置建筑和道路 |
| `systems/economy.py` | 管理玩家金钱、建筑收入，每帧更新 |
| `systems/time.py` | 控制游戏内时间（1秒=10分钟游戏时间） |
| `ui/renderer.py` | 将地图和实体绘制到 Pygame 表面 |
| `ui/hud.py` | 显示金钱、时间、坐标 |
| `ui/event_handler.py` | 捕获按键和鼠标点击，转发给 systems |
