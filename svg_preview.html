1768 张全量生成时会做什么

步骤 说明
1. 视觉构件库 建 ~60 个核心构件（人 / 嘴 / 眼 / 门 / 容器 / 箭头 / 波 / 齿轮 ...）每个词根映射一个
2. 前缀方向覆盖 re- 反向箭头、ex- 向外箭头、in- 向内箭头、sub- 向下、super- 向上...
3. 后缀视觉装饰 -tion/-sion 加上结果环、-er/-or 加上人头、-able 加上"OK"标
4. 防重复保险 每词单独哈希用作变体微调（位移/角度/装饰点数），保证 1768 张全不一样
5. 标签栏 底部黑字写英文词，红字斜体写词根/前缀
