## 模块①：倒闭遗产链

### 设计目标

公司倒闭不是终点，而是"遗产"的开始。倒闭后生成1-3个后续节点，让倒闭的影响延续到世界中：

1. **高管开新公司** — 原公司高管/技术骨干带着经验/专利/人脉开新公司（有旧技术奖励）
2. **专利被竞品收购** — 倒闭公司的专利/技术被竞品公司收购（增强竞品）
3. **员工散布到其他公司** — 原公司员工散布到其他公司（增强人才）

### 实现方案

**新增函数** `generateCompanyAftermath(state, deceasedCid, deceasedCo)`：

```
1. 随机决定遗产节点数：1-3个（基于倒闭公司的规模/健康度/历史事件数）
2. 对每个节点，随机选择遗产类型：
   - 高管开新公司 (40%): 调用 company_spawner.js 生成新公司，继承原公司的 productScore/技术栈
   - 专利被收购 (35%): 随机选一个同/相关行业公司，提升其 productScore 和 talentScore
   - 员工散布 (25%): 随机选2-3家公司，提升其 talentScore
3. 每个遗产节点生成新闻事件
4. 记录到 multi_run_memory.js 的 legacyEvents
```

**遗产节点定义**：

| 类型         | 触发概率 | 效果                                                             | 新闻文案                                                 |
| ------------ | -------- | ---------------------------------------------------------------- | -------------------------------------------------------- |
| 高管开新公司 | 40%      | 生成新公司，productScore继承原公司60%+随机波动，初始市场份额3-8% | "原公司CTO/技术总监宣布创立新公司，带着未公开的专利技术" |
| 专利被收购   | 35%      | 随机同/相关行业公司，productScore+5~~15，marketShare+1~~3%       | "原公司的核心专利被XX公司以XX万收购，技术遗产延续"       |
| 员工散布     | 25%      | 2-3家公司 talentScore+3~8，可能解锁新技能组合                    | "原公司解散后，数百名经验丰富的工程师加入行业其他公司"   |

**集成点**：

- `enterprise_fate.js` 的 `recordCompanyDeath()` 函数末尾调用 `generateCompanyAftermath()`
- `multi_run_memory.js` 新增 `legacyEvents` 数组存储遗产事件历史

## 模块②：新公司自然生成

### 设计目标

每半年（游戏时间）有一定概率从"废墟"中生成新公司，继承已倒闭公司部分参数，保持商业生态的动态新陈代谢。

### 实现方案

**现有代码**：`company_spawner.js` 已有 `checkAndSpawnNewCompanies()` 和 `generateNewCompany()`

**需要增强**：

1. 新增 `spawnFromRuins(state)` — 从已倒闭公司中随机选择一个，继承其部分参数生成新公司
2. 集成到 `tickEnterpriseFate()` — 每180天（半年）触发一次检查
3. 生成概率：50%（保持稀缺感）

**继承规则**：

| 参数     | 继承方式                                   |
| -------- | ------------------------------------------ |
| 行业     | 直接继承倒闭公司的行业                     |
| 健康度   | 倒闭公司最终健康度 × 0.3 + 随机波动        |
| 产品分数 | 倒闭公司最终 productScore × 0.5 + 随机波动 |
| 人才分数 | 倒闭公司最终 talentScore × 0.4 + 随机波动  |
| 市场份额 | 2-5%（新公司起步）                         |
| 文化标签 | 随机（不继承）                             |
| CEO特质  | 随机（不继承）                             |

**集成点**：

- `tickEnterpriseFate()` 末尾新增半年检查：`if (state.player.day - lastRuinsSpawn > 180) checkRuinsSpawn(state)`
- `company_spawner.js` 新增 `spawnFromRuins(state)` 函数

## 模块③：多周目继承系统接入

### 设计目标

将已存在的 `inheritance_chain.js` 接入游戏流程，替换当前的简易 `_ngPlusData` 系统。

### 当前状态

- `inheritance_chain.js` 已完整实现（声誉徽章/关系继承/物品继承/梦想进度/技能树/现金计算/应用继承）
- `multi_run_memory.js` 已完整实现（倒闭记录/IPO历史/合并历史/传奇企业/行业变迁）
- **但两者都未接入游戏流程**
- 当前 `main.js` 的 `startNewGame()` 使用简易 `_ngPlusData` localStorage 键，仅支持现金+1个技能继承

### 需要做的改动

#### 1. `main.js` — 替换 `startNewGame()` 中的继承逻辑

**删除**：`_ngPlusData` 相关代码（约50行）

**替换为**：

```js
// 检查是否有上局遗产可继承
var prevState = getPreviousGameState(); // 从存档/多周目记忆读取
if (prevState) {
  var badges =
    typeof calculateReputationBadges === "function"
      ? calculateReputationBadges(prevState)
      : [];
  var relationships =
    typeof inheritRelationships === "function"
      ? inheritRelationships(newState, prevState)
      : {};
  var items = typeof inheritItems === "function" ? inheritItems(prevState) : [];
  var dreamProgress =
    typeof inheritDreamProgress === "function"
      ? inheritDreamProgress(prevState)
      : null;
  var skillTree =
    typeof inheritSkillTree === "function" ? inheritSkillTree(prevState) : null;
  var cashInfo =
    typeof calculateInheritanceCash === "function"
      ? calculateInheritanceCash(prevState, badges)
      : null;

  var inheritanceData = {
    badges: badges,
    relationships: relationships,
    items: items,
    dreamProgress: dreamProgress,
    skillTree: skillTree,
    cashInfo: cashInfo,
  };

  applyInheritance(newState, prevState, inheritanceData);
  showInheritanceSummaryModal(inheritanceData); // 显示继承摘要弹窗
}
```

#### 2. `main.js` — 游戏结束/胜利时触发遗产结算

**新增**：`handleGameEnd(state, reason)` 函数

- reason: "death" | "victory" | "retirement"
- 调用 `recordPlaythroughEndEnhanced(state)` 记录多周目记忆
- 调用 `calculateReputationBadges(state)` 计算声誉徽章
- 将遗产数据写入 localStorage（供下局继承）

#### 3. `ui/modal.js` — 新增继承摘要弹窗

**新增函数** `showInheritanceSummaryModal(inheritanceData)`：

- 显示上局徽章/继承现金/继承关系数/继承物品数等
- 显示叙事文案
- 点击"开始新旅程"进入游戏

#### 4. `css/style.css` — 新增继承摘要弹窗样式

#### 5. `state.js` — 确保默认状态包含继承相关字段

## 验证方法

1. **倒闭遗产链**：让一家公司倒闭 → 观察是否生成遗产事件新闻 → 检查新公司/竞品增强/人才散布
2. **新公司生成**：玩到第180天+ → 检查是否有新公司从"废墟"中生成
3. **多周目继承**：一局游戏结束 → 开始新游戏 → 查看继承摘要弹窗 → 验证继承加成是否生效
4. **多周目记忆**：玩多局 → 查看百科"多周目记忆" → 验证倒闭公司/IPO/合并记录是否正确

## 实施顺序

1. **模块① 倒闭遗产链**（核心，依赖最少） → `enterprise_fate.js` + `multi_run_memory.js`
2. **模块② 新公司自然生成**（依赖模块①的倒闭记录） → `company_spawner.js` + `enterprise_fate.js`
3. **模块③ 多周目继承接入**（依赖①②完成后世界才有足够记忆） → `main.js` + `modal.js` + `render.js` + `css`
