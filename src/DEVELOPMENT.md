#### 3. 疾病演化系统

**文件变更**：
- `src/js/data/diseases.js` — **新增**：16种疾病定义，5大分类，4级阶段，演化规则
- `src/js/main.js` — 新增 `addDisease()` + `tickDiseaseEvolution()` + `applyDiseaseEffects()` + `treatDisease()` + `getDiseaseSummary()`
- `src/js/ui/render.js` — 新增 `renderDiseases()` 显示当前疾病
- `src/js/core/state.js` — 新增 `diseases: { active: [] }` 状态字段

**疾病分类与演化路径**：

| 分类 | 演化链 |
|------|--------|
| 消化系统 | 胃溃疡 → 胃出血 → 胃癌 |
| 呼吸系统 | 普通感冒 → 支气管炎 → 肺炎 |
| 心理健康 | 焦虑 → 抑郁 → 重度抑郁 |
| 骨骼肌肉 | 颈椎病 → 腰椎间盘突出 → 坐骨神经痛 |
| 肝脏 | 脂肪肝 → 肝硬化 → 肝癌 |

**疾病分级**：轻微 → 中度 → 重度 → 危重（4级，严重程度0-100%）

**核心机制**：
- 工作风险触发疾病（根据工作类型触发不同疾病）
- 每日演化：严重程度递增、阶段升级、演化判定
- 终末疾病（胃癌、重度抑郁、肝癌）终末期可能致命
- 治疗系统：不同疾病有不同治疗方式（药物/手术/疗法/生活方式）和成功率

### 2026-06-20 — 平衡调参 + 食材联动核实（P0/P1 双任务完成）

**核心改动**：

1. **Amenity 价格调整**（`amenities.js`）
   - 在家做饭：¥15 → **¥12**（降低3元，性价比更合理，需消耗食材）
   - 商业区中餐馆：¥30 → **¥35**（拉开与在家做饭的差距，突出"省钱健康"定位）

2. **疾病触发阈值调严格**（`illnesses.js`）
   - **感冒**：`lowHygieneStreak ≥ 5` → **≥ 7**，`highFatigueStreak ≥ 2` → **≥ 3**（更难触发，避免随机暴击）
   - **抑郁倾向**：`lowHappinessStreak ≥ 10` → **≥ 15**（需要长期低落才触发）
   - **失眠症**：`lateNightActions ≥ 12` → **≥ 15**（适度放宽夜生活容忍度）

3. **延期惩罚改为阶梯式**（`critical.js`）
   - **旧机制**：随机掷骰（20%饿晕 / 15%送医 / 40%路人施舍 / 25%硬撑）
   - **新机制**：按延期次数累积惩罚，第1次轻度 → 第2次中度 → 第3次重度 → 第4次+极端
   - 具体阶梯：
     - **饥饱**：第1次健康-3 / 第2次健康-8+40%肠胃炎 / 第3次饿晕(健康-15) / 第4次+送医急救
     - **疲劳**：第1次疲劳+5 / 第2次疲劳+15+35%过劳/失眠 / 第3次过劳晕倒 / 第4次+强制住院
     - **卫生**：第1次心情-3 / 第2次概率患病+名气-1 / 第3次强制患病 / 第4次+多重感染
     - **心情**：第1次心情-5+疲劳+10 / 第2次心情-10+抑郁计数+3 / 第3次整夜失眠 / 第4次+概率重度抑郁

4. **食材联动核实**（`critical.js`）
   - **结论**：✅ 已完整实现，无需补漏

   - `consumeCookingIngredients()` 完整实现：弹出食谱选择 → 检查库存 → 消耗食材 → 记录烹饪经验
   - 支持两种库存格式（数组和对象），食材不足时给出明确提示（缺什么、有多少）
