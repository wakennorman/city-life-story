二、安全玩法
第一招：外部安全三连招
保证网关端口安全
- 确认网关端口是否关闭，如果有，让龙虾关闭就行
网关端口有没有对外暴露？如果有，直接关闭
保证下载安全
- 下载 skill 等外部工具，尽量只从 Clawhub 或者 国内火山引擎搭建的镜像网站 进行下载
- 先查看网站对于 skill 的安全审查评价
[图片]
- 确认要下载前，最好使用 skill-vetter 再进行一次扫描
skill名称
功能简介
下载链接
Skill Vetter
安装 skill 前，检查待下载 skill 的权限、风险，并作出安全评估
skillhub
clawhub
保证在移动端不外露
- 在手机即时通讯软件上使用 clawbot 的时候，尽量只在私聊环境下使用
- 群聊环境会让 clawbot 暴露在风险环境中，有被注入恶意提示词的风险。
第二招：内部安全三连招
内部安全检查 & 修复
openclaw security audit
openclaw security audit --deep
openclaw security audit --fix
内部权限限制
- 如果你的电脑上有特别敏感或机密的文件信息，不希望龙虾操作，可以去 官网 （点此加载）下载一个具备进程隔离和环境封装功能的 Docker。具体的配置教程可在B站查看。
- 如果不用沙箱，为了本地安全，可以对部分内置工具权限进行按需关闭，比如：message、gateway、browser。        
  - message：典型的"对外动作"工具，会把本地上下文与外部沟通渠道（飞书、discord）连起来，可能与其他工具形成信息外泄的链路。
  - gateway：agent 用来管理配置 Gateway 的接口工具。gateway 出错，可能影响整个 OpenClaw：配置失效、服务重启、行为改变、更新到不希望的版本。
  - browser：browser 是 OpenClaw 的浏览器自动化控制工具。如果只是查找和抓取，web_search 或 web_fetch 已经够用了，browser 的自动化权限过高，风险更大。
- 如果工具权限限制不能满足需求，还可以通过提示词对龙虾的权限范围进行限制，让其所有操作都在自己的工作区（workspace）完成，不要触碰工作区外的真实环境。
不要给龙虾共享自己的私人账号
- 切勿把各种账号（诸如：社交媒体账号、浏览器的登录信息、Apple Store 账号等等）共享给龙虾进行操作
- 可以花小钱给它申请一个账号，避免以后花大钱来为它的失误埋单。
