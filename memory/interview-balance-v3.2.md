## 面试机制大修 v3.2（2026-07-06）

### 问题

经典模式开局轻松获得固定职业（教学助理¥4,000/月），前期的临时工作完全鸡肋。面试通过率70%，且无状态/装备/履历要求。

### 设计原则

1. 街头→职场应有显著门槛，临时工不鸡肋，职场不白给
2. 面试是"全方位的考量"——技能、状态、履历、装备缺一不可
3. 玩家需要"准备"面试（提升技能、恢复状态、买正装、积累经验）

### 改动详情

#### 1. 基础概率大修（`enhancedApplyCareerJob`）

- **旧**：基础 70%，属性调整后 clamp 0.3~0.95
- **新**：基础 25% + 工作经验天数×1%。0天→25%，15天→40%，30天→55%，60天→85%
- **设计逻辑**：职场需要"磨"出来，街头工作天数成为硬通货

#### 2. 状态惩罚系统（新）

| 状态       | 阈值       | 惩罚 |
| ---------- | ---------- | ---- |
| 饥饿       | food<25    | -12% |
| 半饥饿     | food<45    | -5%  |
| 极度疲劳   | stamina<20 | -15% |
| 疲劳       | stamina<45 | -6%  |
| 健康差     | health<50  | -12% |
| 亚健康     | health<75  | -4%  |
| 心情极差   | mood<20    | -10% |
| 心情不佳   | mood<45    | -5%  |
| 衣衫不整   | hygiene<20 | -10% |
| 形象欠佳   | hygiene<45 | -4%  |
| 无固定住所 | slum/无房  | -15% |

#### 3. 装备加成（新）

- 正装（suit/formal_shoes/decent_outfit/blazer）：**+15%**
- **设计逻辑**：面试需要得体着装，玩家需要提前购买

#### 4. 技能优势细化（新）

- 技能超过要求每5级+2%（上限+15%）

#### 5. 属性优势（保留）

- 属性超要求1.5倍→+5%/项，属性不足→-15%/项

#### 6. 反馈信息（新）

- 面试失败/成功时显示具体原因（资历浅、状态差、着装加分等）
- 玩家能明确知道"差在哪里"，引导下一步行动

#### 7. 职业路径入门要求补全

- 教学助理：`reqSkills: { english: 5, management: 3 }`（原为空）
- 护理员：`reqSkills: { medicine: 5 }`（原为空）
- reqAttrs 小幅提升

### 设计参考

- **《大多数》**：求职需要良好的状态和装备，直接体现生存压力
- **《Papers Please》**：状态影响工作表现，饥饿/疲劳直接导致失败
- **《This War of Mine》**：生存状态是一切的基础
- **中国职场现实**：面试注重着装、经验、技能、状态
