# 全中文 UI 原则

**核心要求**：游戏中给玩家显示的所有元素必须只能是中文，不能包含任何其他语言（英文、日文、韩文等）。

## 范围

涵盖所有玩家可见的文本内容，包括但不限于：

- 页面标题（`<title>`）
- 游戏标题、Tab 标签、按钮文字
- 属性/需求名称（体质、智力、敏捷、心智、饥饱、疲劳、卫生、心情、健康、名气、发量、尊严、KPI 等）
- 工作/商品/地点/NPC/技能/证书/装备/公司/股票/团队角色的名称和描述
- 新闻标题、模态框标题和按钮、游戏结束/胜利文案
- 消息提示（`StateManager.addMessage()`）
- 时段标签（上午/下午/晚上）、好感度标签（挚友/好友/熟人等）

## 允许保留

- 代码注释和变量名（英文，玩家不可见）
- CSS 类名、JS 变量名（英文，玩家不可见）
- Emoji 图标（📅 💰 🎂 等）
- 货币符号 `¥`（中国人民币标准符号）
- 数字（天数、年龄、金额等）

## 检查流程

每次代码修改后，必须逐项检查全中文清单（见 `src/DEVELOPMENT.md`）。
