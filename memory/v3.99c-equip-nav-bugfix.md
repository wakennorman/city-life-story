# v3.99c 装备购买地点导航 Bug 修复

**Bug**：背包→装备→空槽点击→弹出购买指南弹窗→点击"🗺️ 前往批发市场"按钮无任何反应。

**根因**：`src/js/ui/render.js:4538` 调用 `navigateTo({ type: "location", locationKey: topLoc })` 时：

1. **缺少 `state` 参数** — `navigateTo(state, target, options)` 的第一个参数必须是 `state`，否则 `target` 被当作 `state` 传进去
2. **属性名错误** — 传入 `locationKey`，但 `navigation.js` 期望的属性名是 `key`

**对比正确用法**（同文件第6644行）：

```js
navFn(state, { type: "location", key: t.location });
```

**修复**：`navigateTo(state, { type: "location", key: topLoc })`

**Commit**: `b8e04f7c` (导航参数修复) + `a201e3f8` (map→city Tab修复)

**影响域**: 域F (UI/UX)

**修复2**：当玩家已在目标地点时，_doNavigate 试图切换到 `"map"` Tab，但 TAB_RENDERERS 中已无此 Tab（v3.7 重构改名为 `"city"`），导致 `render_infra.js` 显示 "📌 开发中..."。将 `navigation.js:443` 默认值 `"map"` → `"city"`。

**Why:** 这是一个典型的参数传递 bug。`render.js` 内 `navigateTo` 在训练地点导航处调用是正确的（传了 state），但在装备购买导航处遗漏了 state，导致函数内部 `_navCheck(state, target)` 拿到的 target 不完整，`target.type` 和 `target.key` 均为 undefined，直接 return false。

**How to apply:** 无 — 已修复并 commit。网络恢复后 `git push origin main`。
