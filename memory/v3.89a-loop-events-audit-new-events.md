## 🟢 指令二：新增5个联动事件

### 新增事件清单

| 事件ID | 触发条件（一行摘要） | 联动了哪些系统 | 后续链式？ |
|--------|-------------------|---------------|-----------|
| `hustle_regular_client` | sideHustle活跃≥7天 + reputation≥15 | 副业系统+口碑+现金 | 否（repeatable:false） |
| `repair_expert_identify` | repair技能≥40 + 街头阶段 | 技能系统+道德+名声 | 否 |
| `npc_deep_secret_opportunity` | 任一NPC好感≥80 + 已结识 | NPC关系+现金+心情 | 否 |
| `weather_market_storm` | stormy/rainy天气 + 批发市场 + tradeFreq≥3 | 天气+位置+交易频次 | 否 |
| `hunger_streak_collapse` | lowHungerStreak≥3 + health<60 | 需求积累+健康 | 否 |

### 设计意图

1. **老手特遇** (`hustle_regular_client`)：填补"玩家长期做副业后获得稳定客户"的空白，让 sideHustle.reputation 有叙事回报
2. **专业技能视角** (`repair_expert_identify`)：修理技能≥40后能识别假冒伪劣，让高技能培养有独特事件视角
3. **NPC暗线机会** (`npc_deep_secret_opportunity`)：好感≥80的NPC深夜发来预警信息，验证NPC社交投资的长期回报
4. **天气×位置组合** (`weather_market_storm`)：暴雨在批发市场触发独特事件（帮摊主/拍照/逃跑），增强世界沉浸感
5. **饥饿积累爆发** (`hunger_streak_collapse`)：连续3天饥饿值低触发身体崩溃，体现"欠债总是要还"的游戏哲学
