# 实时新闻抓取系统 v2.0

**2026-07-03 实装** — 游戏最大特色：开局时自动从互联网抓取当日真实新闻，用作游戏世界氛围基调。

## 架构：3层降级抓取引擎

| 层级   | 源                                                     | 依赖              | 延迟  |
| ------ | ------------------------------------------------------ | ----------------- | ----- |
| Tier 1 | rss2json.com 中转新浪财经/36氪/华尔街见闻/新浪科技 RSS | 免费，无需API Key | ~1-2s |
| Tier 2 | 天行数据 API (可选配置)                                | 用户注册免费 Key  | ~0.5s |
| Tier 3 | 预存 90+ 条新闻                                        | 离线永远可用      | 0ms   |

## 第44轮优化（2026-07-03）

### 新闻源替换 — 宏大叙事 → 专业财经/商业

| 旧源（已移除）     | 新源（已添加） | 特点                    |
| ------------------ | -------------- | ----------------------- |
| 新浪新闻（社会）   | **新浪财经**   | 专业财经数据，客观金融  |
| 网易新闻（社会）   | **36氪**       | 商业/科技创投，数据驱动 |
| 人民网时政（政策） | **华尔街见闻** | 专业金融市场资讯        |
| 保留新浪科技       | —              | 科技新闻仍有价值        |

### 分类引擎强化

- **新增「金融」规则**：30+ 金融市场关键词（股市/基金/IPO/债券等）
- **新增「消费」规则**：20+ 消费市场关键词（零售/电商/餐饮等）
- **经济规则大幅扩展**：20+ 经济指标关键词（GDP/CPI/PMI/汇率等）
- **社会规则缩窄**：去掉宽泛词，改为真正社会话题
- **默认兜底不再「社会」**：5级智能降级（含数字→经济 / 含金额→经济 / 含企业→产业 / 含基建→城市 / 无匹配→综合）

### 预存新闻扩充

- 经济：6→14条，就业：6→9条
- 所有新增条目都带 `investmentEffect` 全系统影响

## 关键词分类引擎

8大分类规则（就业/房产/科技/经济/金融/消费/社会/政策/产业/节日/能源），通过正则匹配头条标题+描述，自动判断每条新闻的 `sectorHeat` 影响和 `marketMood` 情绪。

## 后台预加载

- 页面加载 1 秒后自动后台抓取
- 用户浏览菜单期间新闻已就绪
- 若仍在加载：显示等待动画（3.5 秒自动降级）
- 30 分钟缓存有效期

## UI 标识

- 实时新闻显示「🔴 实时」红色徽章（脉冲动画）
- 加载状态：旋转动画 + 进度条 + 跳过按钮
- 消息日志：实时→"实时头条"，预存→"今日头条"
