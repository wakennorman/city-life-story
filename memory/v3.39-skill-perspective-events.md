# v3.39 专业技能视角事件

## 新增事件

| 事件id                | 触发条件                           | 选项                               | 设计心理学                         |
| --------------------- | ---------------------------------- | ---------------------------------- | ---------------------------------- |
| `repair_pro_insight`  | repair.level≥40, day≥30, 90天冷却  | 报告居委会(+道德+回报)/不管/自己修 | 禀赋效应（珍视技能带来的洞察力）   |
| `coding_digital_edge` | coding.level≥30, day≥40, 120天冷却 | 写爬虫套利(+¥800-1500)/记下来/无视 | 信息不对称（技能带来独特世界视角） |

## 设计意图

- **让技能"看得见"**：技能等级不止是数字，而是改变玩家感知世界的方式
- **激励长期修炼**：高级技能解锁更丰富的事件选择，让玩家期待"技能高了会怎样"
- **全剧本适配**：基于通用 skill.level 字段，任何剧本中修炼技能都能触发

## 后续可扩展

- cooking ≥ 50 → 能分辨食材真伪/餐厅后厨技艺
- driving ≥ 40 → 能判断二手车况/规划最优路线
- sales ≥ 50 → 能看穿谈判对手的心理价位
- english ≥ 40 → 能获取外网独特信息/看懂国际新闻

**Why:** 现有技能系统只是数值加成，缺乏"技能改变世界观"的叙事反馈。

**How to apply:** 后续可按此模式为其他6个技能各添加1个视角事件，形成完整系统。
