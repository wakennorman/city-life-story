# v3.3 创业门槛降低 + MC AI 健康底线

## 触发

按 v3.1 审查改进 — 机制/数值审查（MC 1000天模拟驱动）

## 问题

经典模式创业启动资金 ¥30,000，街头工作者日均净收入 ~¥20，需 1,500 天（4 年游戏时间）。街头→创业路径实际上不可达。

MC 模拟（5 trials × 365天）：corporate 策略 100% 死亡，grinder 策略 80% 死亡。

## 改进

### 游戏代码（startup.js）

| 剧本                        | 旧值 | 新值     |
| --------------------------- | ---- | -------- |
| classic/laid_off/fresh_grad | ¥30k | **¥15k** |
| foreign_worker              | ¥20k | **¥10k** |
| small_town/s2gen/midlife    | ¥50k | **¥25k** |
| floor                       | ¥20k | **¥10k** |

### MC AI（monte_carlo.cjs）

- grinder: health<25→workLimit=3 + hygiene<15→洗澡¥10 → 存活率 20%→40%
- corporate: health<50→停学 + cash<500→先工作 + 学频每3天 → 存活率 20%→80%
- mcRegisterStartup: 门槛 30000→15000

## 验证

MC 5 trials × 365天：balanced 100% / grinder 40% / trader 100% / social 80% / corporate 80% ✅
