## 2. 设计层面的核心差距（按严重度排序）

### P0: 后期"无事可做" / 经济天花板

**现象**：MC中位现金 ¥36-57k（约Day 300），之后增长极慢。玩家没有目标可达：

- 创业门槛 ¥200k（v3.11 调高） → MC 中永远到不了
- MC corpPhaseRate=0% → 创业系统在 MC 中从未触发
- 公司阶段形同虚设 → Dead content

**参考设计**：

- BitLife: 买房 → 结婚 → 生子 → 孩子出息 → 遗产循环。每阶段有新目标
- 《退休模拟器》: 还债 → 攒钱 → 学技能 → 晋升 → 退休惬意生活。清晰的阶段弧线
- Stardew: 农场升级 → 矿井 → 社区中心 → 沙漠矿场。永无止境的量化进度

**建议修复（改玩法机制而非数值）**：

1. 降低创业门槛到 ¥50k（参考现实：小店启动资金 3-5 万）
2. 或增加一个"中期目标"：买房（¥50-100k）→ 有了房解锁"租房副业"被动收入
3. 物业费 0.03%/天 在 ¥50k 资产下每天才 ¥15 → 太轻

### P1: 策略同化（6个MC策略本质上是同一个"工作机器"）

**现象**：所有 6 个 MC 策略都走了"吃饭→工作→睡觉→偶尔技能/娱乐"的同一循环。没有真正的策略分化。

**参考设计**：

- BitLife: 有人犯罪致富，有人埋头读书成为教授，有人健身当模特。完全不同的路径
- Stardew: 纯农夫 / 矿工 / 钓鱼王 / 社区粘性。4种完全不同的玩法
- Papers Please: 放行所有 ↔ 严格守法 ↔ 帮反抗组织。道德轴分化

**建议修复**：

1. 增加"灰色路径"：高风险高回报的非法/灰色选择（诈骗、偷窃、违禁品生意）
2. 增加"社交攀升"：好感的最终价值不只是解锁工作，还能提供被动收入/分红
3. 增加"房产收租"：买房后产生被动收入现金流，改变 economics

### P2: 中期目标缺失（Day 30-300 是真空期）

**现象**：玩家 Day 30 还清债务后进入长期无反馈期。癌症期/无目标期。

**参考设计**：

- 《暗黑破坏神》：每 15 分钟一件新装备 → 持续的正反馈
- BitLife: 买房 → 买车 → 结婚 → 生子 → 每个决策点都是小成就
- 《你的人生》：每周一个关键选择题推动叙事

**建议修复**：

1. 增加"人生目标"系统：买房 / 结婚 / 创业 / 退休 — 每个给路线图+阶段激励
2. 买房后解锁"家"子系统：装修/囤货/出租。新的经济深度

### P3: 疾病系统过严

**现象**：慢性病一旦得上，恢复率 +1/天 远低于症状扣血率 -2~3/天。

**参考设计**：

- BitLife: 高血压/糖尿病可控（吃药就不掉血），癌症需手术但有治愈可能
- 《大多数》：疾病扣属性但不致命（除非不看）
- 现实中国：慢性病可控，预期寿命 78+

**建议修复**：

1. 慢性病月费系统（£高血压 300/月吃药，吃药则 symptom -1/月而不是 -2/天）
2. 医疗系统应有"治愈"按钮（花钱治好慢性病），而不是只能等自然康复
3. 医疗险改为"全报销"而不是"部分报" — 买保险 = 疾病扣血归零

### P4: UI 顶栏信息密度不足

**现象**：顶栏仅展示 现金/欠款/住所，核心状态（健康/疲劳/心情）隐藏在第二屏。

**参考设计**：

- 城市浮生记 之前移动端设计四行方案（2026-07-03）：顶栏 / 时间槽 / 位置背包 / **常驻状态条** ✅
- 这一步已做 ✅

## 5. 世界级游戏的设计公理（反思我们的设计）

参考 GAME_BLUEPRINT.md 的四大公理，诊断：

1. **世界自洽** ✅ 经济循环（收入 - 支出 = 储蓄）是封闭的
2. **涌现式叙事** ⚠️ 事件系统丰富，但 40% 的事件是"给你钱/扣钱"这种简单因果
3. **多重路径** ❌ 6条MC路径其实都是同一策略（工作→攒钱→住房）
4. **反馈密度** ⚠️ 日级反馈强，周/月反馈弱

**要成为世界级文字生存游戏，最需要补的是第 3 点"多重路径"**：

- 犯罪路径：偷窃风险高收益高，被抓入狱
- 社交路径：NPC好感长期投资 → 分红 / 合伙创业 / 遗产
- 房产路径：买房 → 收租 → 炒房 → 地产大亨
- 创业路径：摆地摊 → 小门面 → 公司 → 集团（当前需要但门槛过高）

## 参考游戏详细数据

### 《大多数》（2022毕业作品，B站 800 万播放）

- 来源：中国底层打工人真人真事
- 核心：摆摊 + 打工 + 还债
- 结局：多种（还清/家庭破裂/成功）
- 教训：真实感比趣味性更重要

### BitLife（Candywriter, 累计下载 100M+）

- 来源：经典文字人生模拟
- 核心：每日决策 → 人生蝴蝶效应
- 深度：属性 -> 事业 -> 关系 -> 财富
- 教训：**选择比剧情重要**，"如果当初选另一个"驱动重玩

### Stardew Valley（ConcernedApe, 销量 2000 万+）

- 来源：牧场物语独立精神续作
- 核心：生产循环 + 探索 + 社区
- 深度：技能树 + 社交 + 矿场 + 收集
- 教训：**量化进度**（金心、技能等级、博物馆捐赠）是留存的命脉

### 城市浮生记的定位卡

- 在真实感维度对标《大多数》
- 在内容广度上对标 BitLife
- 在玩法深度上对标 Stardew Valley
- **需要融合三者优点**
