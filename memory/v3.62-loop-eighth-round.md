## v3.62 循环产出

### 目标

填补最后3个零事件覆盖地点：`suburb`（郊区）、`gov_office`（政府办事大厅）、`trainingCenter`（培训中心）。

### 新增事件

| 事件                        | 地点            | 触发条件 | 选择数 | 设计心理学                           |
| --------------------------- | --------------- | -------- | ------ | ------------------------------------ |
| `suburb_storm_shelter`      | 🌆 郊区         | day≥3    | 3      | 损失厌恶：暴雨中3种选择×不同健康代价 |
| `gov_office_tout_encounter` | 🏛️ 政府办事大厅 | day≥5    | 3      | 道德困境：¥100黄牛 vs 排队 vs 举报   |
| `training_cert_scam`        | 📚 培训中心     | day≥10   | 3      | 风险决策：¥2000报班30%真收益/70%被骗 |

### 特性要点

- **郊区暴雨庇护**：利用 `suburb` 独有的 `weatherEffects` 字段，暴雨场景天然契合郊区「交通不便」特征；3种选择从最优（进屋躲雨，健康+2/心情+3/疲劳-5）到最差（冒雨跑，健康-3/卫生-10/心情-3），形成梯度决策
- **办证黄牛**：政府办事大厅的 `specialActions`（办身份证/护照/社保卡等）是黄牛生存的土壤；3条路径对应道德三档（举报+5/排队+2/黄牛-3）
- **包就业培训陷阱**：培训中心「投资自己」的定位天然吸引技能焦虑；¥2000高投入×30%真收益，映射现实培训乱象；「核实」选项教会防骗意识
