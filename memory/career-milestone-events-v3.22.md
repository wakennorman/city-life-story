# v3.22 — 职业里程碑叙事事件 + 带薪年假

## 核心变更

### 里程碑叙事事件 (`src/js/data/job_milestone_events.js`)

9个街头工作（废品回收/工地力工/工厂组装/摆摊餐饮/外卖骑手/家教/内容写作/街头卖艺/银行安保），每个在 7/30/100 天触发叙事选择事件。

**设计原则**：峰终定律 + 真实中国打工场景 + 每次选择都有后果。

| 阶段 | 线     | T1 (7天)   | T2 (30天)      | T3 (100天)                  |
| ---- | ------ | ---------- | -------------- | --------------------------- |
| 废品 | 老周线 | 请你吃饭   | 介绍去富土康   | 片区废品生意交接            |
| 工地 | 老李线 | 给红包     | 介绍干技术活   | 推荐去亲戚工厂当正式工      |
| 工厂 | 组长线 | 给饭票     | 推荐考证书     | 质检员职务空缺（送礼/竞聘） |
| 摆摊 | 老王线 | 点评手艺   | 介绍去美食广场 | 退休传配方+推车             |
| 外卖 | 站长线 | 提醒买保险 | 跑腿外包单     | 推荐当区域小队长            |
| 家教 | 家长线 | 转账+好评  | 介绍其他生源   | 机构挖角当全职讲师          |
| 写作 | 编辑线 | 鼓励红包   | 推荐商业单     | 内容合伙人邀约              |
| 卖艺 | 阿姨线 | 鼓掌+打赏  | 酒吧驻唱邀约   | 乐队正式演出机会            |
| 安保 | 老张线 | 请烟       | 介绍考保安证   | 推荐当队长                  |

### 带薪年假 (`career_dev.js`)

带薪年假：在职≥90天，冷却180天，倦怠≥30。效果：倦怠-45/心情+25/精神+15/健康+8，代价扣5天薪资。工作行动UI新增按钮。

**Why:** 职业系统的长期游玩欲望来自两个核心机制：(1) 叙事峰值——里程碑事件让每个工作有"故事"；(2) 可控节奏——带薪年假让倦怠系统有真正的"大招"回血。

**How to apply:** 新增工作只需要在 `job_milestone_events.js` 的 `JOB_MILESTONE_EVENTS` 对象中添加对应条目，系统自动在 7/30/100 天触发。main.js 的 3 个称号升级点已有统一调用。
