# 开局抓人设计 SOP（新剧本必须遵守）

## 核心公式

**具体数字 × 人物关系 × 道德困境 × 倒计时 × 情感温度**

参考标杆：《大多数》——父亲赌债¥20000→高利贷逼婚妹妹→1个月内必须攒够¥20000。

## 每个剧本必须交付的5件事

1. **核心情感钩子（1句）** — 玩家看到时心里会产生什么具体情绪
2. **description升级版**（≤350字）— 含至少1个有名字的NPC、具体金额、道德灰度
3. **startingMessage升级版**（≤130字）— 第一人称临场感+感官细节+悬念/逼迫感
4. **startEvent升级版**（title+text≤220字+effects）— 愿意截图分享的叙事密度
5. **30秒留存机制** — 第1个行动点的情感张力设计

## 参考游戏分析维度

| 游戏                 | 核心拆解                                       |
| -------------------- | ---------------------------------------------- |
| 《大多数》           | 社会现实主义+数字锚点+亲情情感债务             |
| 《Papers Please》    | 即时道德压力+规则内人性张力+第一天不可能的选择 |
| 《This War of Mine》 | 开场残酷现实+立刻分配"你要保护谁"              |

| 《BitLife》          | 极简即时可玩+每个结果都有代价                  |
| 《中国式家长》       | 家庭期望压力+中国社会压力具象化                |

## 经典模式与沙盒模式特殊处理（2026-07-04 补充）

### 经典模式（城市务工者）

- 已有所有5要素，重点在 startEvent 结尾：从"被动宣言"改为"主动出发"
- 四川大叔是现有描述中的NPC，startEvent 必须让他发言、给出第一个行动方向（工地/日工/具体地点）
- 结尾用动作句代替宣言句："你站起来，抖掉纸板上的灰" > "先活下去"

### 沙盒模式

- 无固定叙事，但必须有"命运定锚"弹窗
- 实现方式：startSandboxGame() 内先 showModal，弹窗动态显示 cfg.cash/debt/age，3个挑战选项：
  - 💰 百日攒¥50,000
  - 📈 打工人逆袭开公司
  - 🚀 自由探索（无目标）
- 选中的挑战存入 state.flags._sandboxChallenge，开场消息体现该承诺
- 弹窗在沙盒配置界面仍可见的情况下弹出（modal叠加在沙盒屏之上）

## 技术约束（务必遵守）

1. 纯HTML+CSS+原生JS，不引入外部库
2. 全中文UI，贴近中国社会现实
3. 任何新机制必须7个剧本全部兼容
4. description≤350字，startingMessage≤130字，startEvent.text≤220字
5. 对话用「」，不用"" 避免JS字符串转义问题

## 开局反模式（避免）

- 只有物质困境，没有人物关系
- 缺少倒计时/明确截止日期
- 数字不具体（"很多债"→应该是"¥20000村债"）
- startEvent是流水账，无情感密度
- startingMessage像NPC介绍而非第一人称临场感
