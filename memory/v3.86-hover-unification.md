# v3.86 统一悬停动效（2026-07-11）

以 `action-card:hover` 为标准，统一所有可点击卡片和按钮的悬停动效。

## 标准定义

```css
.action-card:hover {
  background: var(--bg-card-hover);
  border-color: var(--accent);
  transform: translateY(-1px);
  box-shadow: 0 4px 12px var(--accent-glow);
}
```

## CSS 类改造清单

| CSS 类                          | 改造内容                              |
| ------------------------------- | ------------------------------------- |
| `.card:hover`                   | 加 bg + translateY + shadow           |
| `.hustle-card:hover`            | 加 bg + translateY + shadow           |
| `.btn:hover`                    | border-color → accent + lift + shadow |
| `.btn-primary:hover`            | 加 lift + shadow                      |
| `.world-news-item:hover`        | 加 translateY + shadow                |
| `.world-news-skip-btn:hover`    | 抛弃自定义,统一为标准                 |
| `.marketing-channel:hover`      | bg-secondary→bg-card-hover + lift     |
| `.team-management-action:hover` | 从仅border-color→完整标准             |
| `.npc-visit-btn:hover`          | 保留颜色互换 + 加lift + shadow        |

## 内联 JS onmouseover 统一（9处）

所有 `onmouseover="this.style.borderColor='var(--accent)'"` 升级为完整 lift + shadow + bg 效果。

**Why:** 此前不同可点击元素有各自独立的 hover 效果（有的只改 border-color，有的只改 bg，有的完全没动效），体验不统一。

**How to apply:** 新增卡片或可点击元素继承相应 CSS 类即可自动获得标准悬停动效。
