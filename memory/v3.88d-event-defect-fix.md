**修复内容**：地毯式扫描212+事件的叙事-触发自洽性，修复3类缺陷

**修复清单**：

1. **15个事件缺phase字段永不触发**
   - personal_growth_events.js: 5事件补 `phase:'street'`
   - workplace_social_events.js: 5事件补 `phase:'corporate'`
   - insider_trading_events.js: 5事件补 `phase:'street'`
   - 根因：`queueRandomEvent()` 的 `filter(e.phase===phase)` 过滤掉所有缺 phase 的事件

2. **NPC叙事-触发断链**: minimum_wage_hike 引用"王婶"但无 aunt_wang.met 守卫

3. **动态文本渲染错误**: career_promo_offer 的 `text:function(st)` 在 showEventModal 中渲染为 "[Function]"

**Why**: 这些事件自创建以来从未被触发过（缺phase）或会异常显示（动态文本），属于严重影响游戏体验的缺陷。

**How to apply**: 后续新增事件文件必须包含 `phase` 字段；事件的 `text`/`story` 字段应为字符串而非函数；引用命名NPC时必须守卫 `relationships.X.met`。
