# v3.63 开局新闻深度联动修复

## 问题诊断

用户反馈开局新闻弹窗中的 💡 note 文字（如"科技/AI岗位薪资上涨""裁员降薪潮来袭"）完全是**死内容**——只在弹窗显示，不实际影响游戏任何系统。

### 根因分析

1. **新闻note不生效**：`WORLD_NEWS_DB` 条目中的 `worldEffect.note` 只是字符串提示，没有映射到 `jobBonus`/`priceMod`/`skillXp` 等实际游戏效果
2. **投资联动缺失**：AI/科技类新闻的 `investmentEffect` 只影响股票价格，但 `note` 中提到的"编程和数码技能更值钱"从不转化为技能XP或工作加成
3. **ID匹配断裂**：开局新闻注入 `activeNews` 时加了 `"intro_"` 前缀，但 `news_driven_events.js` 的条件检查用的是原始ID（如 `"construction_boom"`），永远匹配不到
4. **玩家无参与感**：开局新闻弹窗只有"阅读→点击→进入"，玩家不能做任何选择来影响初始状态

## 修复方案

### 1. `applyWorldNewsToParams` 增强 — 从note到实际效果

**文件**: `src/js/core/world_news_intro.js`

在 `applyWorldNewsToParams` 中新增对 `jobBonus`/`jobPenalty`/`priceMod`/`skillXp`/`cashBonus`/`cashLoss` 的解析：

- 支持两种 jobBonus 格式：`string[]`（旧）和 `{id, mul}[]`（新）
- 解析 `skillXp` 映射到 `state._introSkillXp`
- 解析 `cashBonus`/`cashLoss` 到 `state._introCashBonus`
- 解析 `priceMod` 到 `state._introPriceMods`

### 2. 新增 `applyIntroNewsDirectEffects` — 开局新闻即时生效

**文件**: `src/js/core/world_news_intro.js`

在 `applyNewsAndEnter` 中新增调用，将开局新闻的直接影响立即应用到游戏状态：

- **工作加成** → 写入 `state._jobMultipliers`（与 `news.js` 的 `applyNewsEffect` 一致）
- **价格修正** → 直接修改 `state.trade.goodsPrices`（与 `news.js` 一致）
- **技能经验** → 直接增加 `state.skills[x].xp`
- **资金调整** → 直接修改 `state.resources.cash`
- **投资开盘价** → 修改 `INV_STOCKS` 对应标的的 `mkt.price`，记录 `openPrice`

### 3. `applyNewsAndEnter` 重构 — 双ID注入 + 影响日志

**文件**: `src/js/core/world_news_intro.js`

关键改动：

- **双ID注入**：每条开局新闻同时以原始ID和 `"intro_"` 前缀ID注入 `activeNews`
- **效果合并**：`combinedEffects` 合并 `investmentEffect` + `worldEffect.jobBonus` + `worldEffect.priceMod` 等
- **影响日志**：每条新闻的游戏影响都以 `StateManager.addMessage` 形式写入日志，让玩家看到"这对我意味着什么"

### 4. 新增开局选择面板 `buildIntroChoicePanel` + `applyIntroChoice`

**文件**: `src/js/core/world_news_intro.js`

- 根据新闻标签和内容动态生成2-3个开局选择
- 选择影响：初始资金、技能XP、需求值、flags
- 可选：💻 报名编程培训班 / 🛒 先找零工过渡 / 🏦 把钱存定期 / 💼 立刻找工作 / 🚶 先逛逛城市

### 5. `news_driven_events.js` — ID兼容层

**文件**: `src/js/core/news_driven_events.js`

- 新增 `_hasNewsId()` 辅助函数，自动匹配原始ID和 `"intro_"` 前缀ID
- 所有事件的 `conditions` 函数都改用 `_hasNewsId()` 替代手动遍历
- 确保开局新闻也能触发叙事事件

### 6. `generateInvestmentEffectFromTag` 扩展

**文件**: `src/js/core/world_news_intro.js`

新增标签映射：

- AI → 科技行业 ×1.15
- 芯片 → 科技行业 ×1.18
- 机器人 → 科技行业 ×1.12
- 大数据 → 科技行业 ×1.10
- 加密货币 → 虚拟币 ×1.15
- 黄金 → 贵金属 ×1.08
- 能源 → 新能源 ×1.12
- 医疗 → 医药 ×1.08

### 7. `WORLD_NEWS_DB` 条目增强

**文件**: `src/js/core/world_news_intro.js`

关键条目新增实际效果：

- `emp_ai_replace`: 新增 `jobBonus`（coding_freelance +15%, data_entry -10%）+ `skillXp`（coding +5, logic +3）
- `emp_finance_hiring`: 新增 `jobBonus`（accounting +12%, financial_advisor +15%）

## 设计哲学

> "新闻不只是世界背景，它是玩家踏入城市时遇到的第一个'系统'。每条新闻都应该像《大多数》中的政策公告——读完就知道对自己打工生活有什么影响。"

## 测试要点

1. 开局新闻弹窗显示后，选择面板应出现2-3个选项
2. 点击选择后，对应效果应立即生效（资金/技能/flags）
3. 点击"出发"后，消息日志应显示每条新闻的具体影响
4. 投资Tab应显示开盘价变化
5. 工作Tab中相关工作的收入应有加成
6. 商品市场中的商品价格应按新闻调整
7. 后续新闻事件中，开局新闻也应能正确触发 `news_driven_events.js` 中的条件
