# v3.5x 新闻系统深度影响链条全面修复

## 修复6大新闻传导断层

### 1. 新闻→疾病概率 (`illness.js` + `news_event_bridge.js`)

- NEWS_ILLNESS_MAP: flu_surge(×1.8) / cold_wave(×1.4) / heatwave(×1.3) / 医疗利好转×0.85
- runDailyNewsBridge 每日计算→`state.flags._newsIllnessMod` → `rollIllness()` 读取

### 2. 新闻→住所租金 (`news_event_bridge.js` + `daily_pipeline.js`)

- NEWS_HOUSING_COST_MAP: rental_crisis(×1.3) / 政策利好(×0.88) / 人口流入(×1.15) 等11条
- `getNewsHousingCostModifier()` → 租金管线读取→`rentAmount`自动应用

### 3. 新闻→副业收益 (`news_event_bridge.js` + `side_hustle.js`)

- NEWS_SIDEHUSTLE_MAP: 21条修正映射（6种副业类型×新闻）
- HUSTLE_TYPE_MAP 映射副业ID→类型
- `performHustle()` → `getNewsSideHustleModifier()` 修正收入

### 4. 新闻→旅行成本 (`news_event_bridge.js`)

- NEWS_TRAVEL_COST_MAP: 能源危机×1.3/节日旺季×1.4/通缩淡季×0.88

### 5. 新闻→玩家士气 (`news_event_bridge.js`)

- NEWS_MORALE_MAP: 20+情绪映射（好消息/坏消息）
- 根据玩家经济状况动态强度
- 阈值概率触发+ happiness delta

### 6. 新闻→城管热度+创业环境+每日目标

- NEWS_CHENGGUAN_MAP: crackdown/+25 heat 等
- NEWS_ENTREPRENEUR_MAP: 14条创业成本修正
- `daily_quest.js`: 17条新闻→目标映射 + 6扩展检查类型
