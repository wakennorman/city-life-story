## 新增：街坊声望系统

### 核心机制

在同一地点持续工作/交易/社交 → 声望增长 → 解锁等级称号 + 收入加成

| 等级 | 称号     | 所需声望 | 收入加成 | 特殊效果             |
| ---- | -------- | -------- | -------- | -------------------- |
| 0    | 新面孔   | 0        | 0%       | —                    |
| 1    | 熟客     | 10       | +3%      | 摊主记得你的脸       |
| 2    | 老熟人   | 25       | +7%      | 见面打招呼           |
| 3    | 街坊     | 50       | +12%     | 触发归属感里程碑事件 |
| 4    | 地头蛇   | 75       | +18%     | 说话好使             |
| 5    | 一方之霸 | 90       | +25%     | 这条街你说了算       |

### 动态平衡

- **增长**：每次工作 +1 声望（本行工作额外 +0.5）
- **衰减**：每日 -1（高等级衰减更慢，Lv4+ 每2天-1）
- **衰减保护**：玩家不需要每天刷脸，几天不去不会掉太多

### 里程碑事件

达到"街坊"（Lv3）触发归属感二选一事件：

- 「真好，有归属感了」→ 心情+10
- 「还不够，我要去更高的地方」→ 名气+2，¥500

### 设计参考

- Stardew Valley 村民好感度 — 逐步解锁回报
- 大多数 区域熟悉感 — 常驻地点的经济优势
- GTA 区域声望 — 每个区域有独立的声望系统
