# v3.99 全系统UI统一性审查

## 审查范围

2026-07-13 全系统优化 8域轮换中的UI统一性审查，涵盖：

### 域F (UI/UX) 二次审查 — 3项修复

| #   | 问题                                                                                                              | 修复                                                                                                                                                                                                                                                                                                       |
| --- | ----------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ①   | **手机端状态条不一致**：第1行属性无色带、第2行需求有色带，视觉分裂                                                | `render_infra.js:1169` `buildRow(attrs, true)` 统一加色带。`style.css` 移除 `.mss-cell-no-track`，改为 `.mss-cell-has-track` 统一紧凑间距+色带高度5px。极端窄屏(≤360px)同步适配                                                                                                                            |
| ②   | **"城市地图"→"快速出行"卡片大小不一**：desc文字不定长+inline style散乱导致每张卡高度/宽度不一致，需频繁滑动       | `render.js:2932-2948` 重构为纯CSS class `.quick-travel-btn`，定高52px+flex column居中。desc移入title/tooltip。grid `minmax(140px→120px)` 更密。文字ellipsis防溢出                                                                                                                                          |

### 约式自动归类关联

`action_sort.js` 文档增加 UI 统一标准说明：行动对象的 `category`/`priority`/`disabled` 三个字段构成约定式核心，renderActionsTab 根据 `disabled` 状态自动套用 `.disabled` 类，确保全系统一致。

### 影响文件

- `src/js/ui/render.js` — 快速出行卡片模板重构（-desc + 统一class）
- `src/js/ui/render_infra.js` — 属性行改带色带
- `src/js/core/action_sort.js` — UI约定文档
- `src/css/style.css` — 统一交互标准+全系统 `:active` 补全+黑边框修复

**Why:** 移动端属性/状态条统一性直接影响玩家对角色状态的感知效率；快速出行卡片大小不一导致城市Tab滑动体验差；全系统无统一可点击标准导致桌面/手机端交互反馈割裂。

**How to apply:** 新增 `interactive`/`non-interactive` CSS 类可直接用于新UI元素。`createActionCard` 自动处理 `disabled` 状态。约定式归类扩展确保新行动自动获得正确UI分类和样式。
