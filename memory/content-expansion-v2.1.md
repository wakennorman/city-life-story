# 内容扩充 v2.1 SOP

## 硬约束

1. **街头工作 ≤20 个**（含已有+待实现）— 超过即砍，砍无特色的纯数值条目
2. **行业代表制**：每个行业只留 1 个代表 NPC（同类不重复）
3. **功能内容重质不重量**，不因"扩充"而加无意义数据

## 成套添加

| 新条目   | 必须配套                                                     |
| -------- | ------------------------------------------------------------ |
| **地点** | 1–2 工作 + 1 NPC + 2–3 事件/新闻（均可标记 TODO）            |
| **NPC**  | 3–5 对话（好感分级）+ 1 求助事件链 + 礼物偏好表 + 1 深度任务 |
| **商品** | buyLocations + sellLocations（套利路径）+ seasonal 标注      |
| **证书** | 考试地点 + 费用/通过率 + 生效后具体加成效果                  |

## 交叉验证

- 新增前 `grep` 同名/同功能 — 重复则合并，不新建
- 装备引用的技能必须在 `skills.js` 存在，否则补技能或改引用
- 地点 ID 必须与 `jobs.js` 的 `location` 字段一致
- 空地点（去了无事可做）禁止添加

## 参考来源

- 真实中国数据：统计局/人社部/市场价格（注明年份）
- 游戏：《大多数》《北京浮生记》《动物森友会》等（注明参考哪个系统）
- 自由职业：猪八戒/闲鱼/小红书

## 执行流程

1. 检查缺口 → 成套扩充 → 交叉验证 → 写数据文件 → `python build.py` → `git commit`
2. **每次聚焦 1–2 个文件，每完成一文件一 commit**
3. 更新 DEVELOPMENT.md 变更记录 + MEMORY.md 索引

## 新闻/剧情类不限量

- 新闻事件/道德困境/节日/随机剧情越多越好
- 但必须与其他系统联动：effects/flags 标注影响哪些商品/价格/行业
