# 长期记忆

## 2026-06-26 用户反馈修复

- 每日收支报告不得为了“平衡”伪造支出/收入；未记录现金差额应作为“未归类现金变动”提示，并继续补真实流水埋点。
- 动态表单输入框不要在 `oninput` 中整块重绘容器；姓名、搜索、备注等文本输入应局部更新状态，避免焦点丢失和只能输入一个字符。
- 旧正式入口 `src/index.html` 仍是玩家入口。TS 数据目录/bridge 是迁移通道，玩家反馈修复必须落到 legacy UI 或桥接进 legacy UI。
- 背包、装备、地点、职业等玩家可见文案必须走显示名兜底；内部 id、`undefined`、英文分类不应直接进入 UI。
- 已有开局强制人生目标弹窗后，行动列表不再放“确立/查看/更改人生目标”卡片；目标入口归入“个人成长”的目标区域。
- 资金门槛必须统一来源。创业注册这类流程的卡片展示、按钮禁用、弹窗文案和实际扣款要使用同一个计算函数。
