## 3. 关键技术决策

### 3.1 阿杰跨周目事件的门控设计

原始条件用了 2 个死 flag（`_ajieMetPrevRun`、`_fromAjie`，从未在代码中赋值），会构成死代码。修复：

- 改为真实信号：`!!st.inheritanceBonuses`（NG+继承生效）或 `!!st.flags._ajieTrusted`（本局深交标记，npcs.js:3201 在 deepTask 完成时设置）
- 两个都合理满足"上辈子老朋友"意象

### 3.2 调解 followUp 的"区分度"

- 只有"中性和解"路径触发 `_auntZhangMediated=true` + scheduleChainEvent
- 单边站队路径（帮王婶/帮张姐）不触发——制造玩家选择的分化后果

### 3.3 NPC 链式事件统一接 scheduleChainEvent

仿照 v3.49 已有的 `xiao_mei_techpark_payoff`（12天）、`craftsman_apprentice_payoff`（30天）模式。全部 `typeof scheduleChainEvent === "function"` 守卫。

## 4. Pre-commit 基线同步事件
