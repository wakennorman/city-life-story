**食材库存联动** — ✅ 已完成

**实现内容：**

1. `src/js/data/ingredients.js` — 食材定义（23种食材）+ 烹饪配方（16个配方）
2. `src/js/main.js` — 食材系统核心函数（购买、烹饪、变质检查）
3. `src/js/ui/render.js` — 食材库存UI显示
4. `src/js/core/state.js` — 食材库存状态字段

**食材分类：**

- 主食类：大米、面粉、挂面
- 蔬菜类：青菜、白菜、土豆、西红柿
- 肉类：猪肉、鸡肉、牛肉、鱼
- 蛋白类：鸡蛋
- 调料类：盐、酱油、白糖、辣椒、姜蒜、醋
- 水果类：苹果、香蕉、橘子
- 补充：豆腐、花生

**烹饪配方（16个）：**

| 技能要求 | 配方                                 |
| -------- | ------------------------------------ |
| 1-20级   | 番茄炒蛋、鸡蛋汤、白米饭、清汤面     |
| 21-50级  | 青椒肉丝、红烧肉、麻婆豆腐、手撕白菜 |
| 51-80级  | 鱼香肉丝、糖醋里脊、清蒸鱼、宫保鸡丁 |
| 81+级    | 黑椒牛柳、火锅                       |

**核心功能：**

- `buyIngredient(state, id, qty)` — 购买食材
- `cookRecipe(state, recipeId)` — 烹饪料理
- `tickIngredientSpoilage(state)` — 每日变质检查
- `getIngredientSummary(state)` — 获取食材摘要
- `getAvailableCookingRecipes(state)` — 获取可用配方

**食材机制：**

- 保质期：每种食材有保质期，冰箱延长一倍
- 过期变质：变质食材自动丢弃
- 技能提升：烹饪获得经验，解锁更多配方
- 效果：满足饥饿、提升心情、恢复精力

**UI显示：** 侧边栏显示食材库存（名称/数量/剩余天数/是否过期）
