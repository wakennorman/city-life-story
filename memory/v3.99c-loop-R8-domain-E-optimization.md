## 指令一：A类缺陷修复（4+2 项）

### File: `investment.js` — 4个A类NaN缺陷

| #   | 函数           | 行号  | 缺陷                                                           | 修复                                 |
| --- | -------------- | ----- | -------------------------------------------------------------- | ------------------------------------ |
| 1   | `buyInvStock`  | ~1325 | `cost=NaN` 绕过 `cash<cost` 比较（NaN比较返回false）→ cash NaN | 加 `isNaN(cost)` 守卫                |
| 2   | `sellInvStock` | ~1388 | `revenue=NaN` 直接 += cash                                     | 加 `isNaN(revenue)` 守卫             |
| 3   | `buyBtc`       | ~1416 | 同1，cost=NaN绕过cash不足检查                                  | 加 `isNaN(cost)` 守卫                |
| 4   | `sellProperty` | ~1532 | `prop.currentPrice` undefined → net=NaN                        | 加 `null/isNaN` 防御+回退 `buyPrice` |

### File: `daily_pipeline.js` — 1项全局NaN防御

日递增步骤末尾增加现金NaN检查：`isNaN(cash)||!isFinite(cash)` → 重置为0，防止任意cash损坏持续

### File: `render.js` — 训练系统skill对象兼容修复（用户报告bug）

| #   | 问题                        | 根因                                                        | 修复                                                |
| --- | --------------------------- | ----------------------------------------------------------- | --------------------------------------------------- |
| 1   | `train_social` 点击无反应   | `p.social = {level,xp}` 是skill对象，训练代码当作数字 → NaN | 新增 `_getTrainStatVal`/`_setTrainStatVal` 兼容对象 |
| 2   | `train_medicine` 点击无反应 | 同上，`p.medicine` 为skill对象                              | 同一函数修复                                        |
| 3   | `train_mental` 显示异常     | 显示用 `p[t.stat]                                           |                                                     | 0` 虽值为数字但潜在显示问题 | `_getTrainStatVal` 统一处理 |

**新增函数**:

- `_getTrainStatVal(p, stat)` — 提取数值（数字直接返回，skill对象返回 `.level`）
- `_setTrainStatVal(p, stat, val)` — 设值（数字直接设，skill对象设 `.level`）

**影响的代码点**: render.js 共6处替换（渲染显示×1 + modal显示×1 + curVal提取×1 + 赋值×2 + 风险分支×1）
