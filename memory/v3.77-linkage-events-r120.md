## 设计意图

1. **老手特遇**：填补"玩家长期做某类工作后遇到熟人客户"的空白，让行动频次统计有叙事回报
2. **专业人士视角**：修理技能≥40后在二手市场能识别好货，让高技能有实际游戏价值
3. **NPC意外发现**：老周好感≥60后透露隐藏渠道，验证NPC好感系统的投资回报
4. **天气×位置组合**：同一暴雨天气在不同位置有不同事件分支，增强情境沉浸感
5. **连续低饥饿爆发**：连续3天hunger<20触发身体警报，验证需求系统的积累效应

## 叙事质量自检

- 所有事件的 text/story 在 conditions 全为 false 的玩家眼中也合理（只是不会触发）
- 每个 option 的 apply 里 addMessage 与选项文本一致
- 天气×位置事件使用动态 choices 函数，根据当前位置生成不同选项
