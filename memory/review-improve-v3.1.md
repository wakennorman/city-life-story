# 全方位审查改进 SOP v3.1

> 触发短语：`按 v3.1 审查改进` → Read 本文件 → 执行

## 0. 适用范围

一次"审查改进"请求可以是以下任意一种：

- **小改动 / 单 feature**：只在第 2–5 节中选取相关维度执行，不必全跑；在执行记录里写明"本轮覆盖维度：…"
- **大型 feature / 里程碑 / 发版前**：跑完整 6 节 + v3.1 checklist
- **纯 UI 改造**：必跑 2（机制影响）+ 4（UI/UX）+ 5（留存/NPS）+ 6（蓝图对齐）
- **纯机制改造**：必跑 1（代码）+ 2（数值）+ 3（叙事）+ 6（ Blueprint alignment）

---

## 1. 代码 & 架构

- [ ] 每个改动文件 `node --check` 通过
- [ ] 没有破坏既有公共 API（函数签名/参数顺序/globals）
- [ ] 没有引入循环依赖（A 引 B、B 引 A）
- [ ] 没有死代码、重复代码、过长函数（>150 行建议拆）
- [ ] 新增模块在 `index.html` script 标签顺序中放在正确位置（不要改动已有顺序）
- [ ] 改动在 TypeScript 类型层也没有报错（`npm run typecheck` 全量通过）

## 2. 机制 & 数值平衡

- [ ] 引入的新数值在已有数值区间内合理（参考 `memory/balance-tuning-done.md`）
- [ ] 不存在"只会涨/只会跌"的单向永动机（参考 v2 的房产波动修复）
- [ ] 收益 × 获得概率 = DPS 在线性可玩区间（新人7天能活、30天有盼头、1年不崩）
- [ ] 改动不影响既有成就的达成门槛

## 3. 叙事 & 内容

- [ ] 所有玩家可见文案纯中文（参考 `memory/全中文UI原则.md`）
- [ ] 引用了正确的 NPC 姓名、地点 ID、行业字段（grep 校验）
- [ ] 事件触发条件在全部 7 个剧本中都成立或有降级分支
- [ ] 没有"悬空"的 flag/资源/效果（写了没人用，或用了没写）

## 4. UI / UX（含移动端专项）

- [ ] **手机端（<=480px）关键信息 ≤2 屏内可见**：现金、欠款、背包容量、住所、行动力、时段、紧急提示
- [ ] **关键数值不被遮挡/截断**（顶栏最长见的"钱"和"欠款"必须第一屏可见、不能横划）
- [ ] **触控目标 ≥ 44×44 px**（Apple HIG）；密集按钮间距 ≥ 8 px 防误触
- [ ] **垂直节奏**：行高在 1.4–1.6；最小字号不低于 10 px（避免 mob 看不清）
- [ ] **颜色对比度**：正文 ≥ 4.5:1（WCAG AA），大字 ≥ 3:1
- [ ] **信息层级清晰**：顶栏只放第一优先数值，次优先信息放状态条或 tab 内；不要把 6 个芯片并排在顶栏
- [ ] **一致性**：危险/警告/成功语义色统一（红=danger，绿=success，橙=warning）
- [ ] **桌面端没有回归**：CSS 响应式覆盖必须在两个断点（768/480）之外保持桌面三层结构
- [ ] **没有横向 overflow**（跑 Chrome Headless 375/480/768/1024 视口）

## 5. 留存 / 动机 / 玩家体验

- [ ] 玩家进入第一个 3 分钟内需要知道三件事：我在哪、我该干啥、我有多少钱。UI 必须把这 3 件事在第一屏内显出来。
- [ ] **机会成本可视化**：玩家每个行动之前能看到"时间/体力/心情"三要素的代价
- [ ] **成就密度**：每 5–10 分钟一个新反馈（成就/礼物/升级/新对话）
- [ ] **压力曲线**：前紧（生存压力）→ 中松（小有所成）→ 后紧（阶层跨越压力）
- [ ] **多周目钩子**：缎带、遗产、成就在 NG+ 仍有激励
- [ ] **没有强制弹窗打断节奏**（核心循环外的一切弹窗都可以跳过）

## 6. Blueprint 对齐（参考 `city-life-story/src/GAME_BLUEPRINT.md`）

- [ ] 实现的機能落在 Blueprint P0/P1 优先级矩阵上
- [ ] 新增功能与至少一个 P0 目标对齐（降低上手门槛 / 中期目标感 / 多周目）
- [ ] 实现前查过 Blueprint 公理（世界自洽 / 涌现 / 多重路径）
- [ ] 不会引入新的"玩家无事可做"状态（空地点、空阶段、空事件链）

| small_town_grader | 0 现金、高智力、城中村 | ✅/❌              |             |
| foreign_worker    | 零社会资本、城中村     | ✅/❌              |             |
| second_gen        | 富二代、高起始资金     | ✅/❌              |             |
