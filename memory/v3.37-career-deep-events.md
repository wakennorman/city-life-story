# v3.37 职业系统深度联动事件

## 新增事件

| 事件id                   | 触发条件                        | 选项                     | 设计心理学                         |
| ------------------------ | ------------------------------- | ------------------------ | ---------------------------------- |
| `first_earn_milestone`   | totalEarned≥500, day≥5, 不重复  | 存银行/犒劳自己/买书学习 | 峰终定律（第一次"有钱"的记忆锚点） |
| `workmate_bonding`       | workDays≥20, day≥15, 30天冷却   | 去聚餐/婉拒/带小吃分享   | 社会比较（工友故事→玩家不孤单）    |
| `job_skill_breakthrough` | actionFreq≥30, day≥20, 60天冷却 | 追求速度/精进技巧        | 禀赋效应（技能积累的回报）         |
| `career_doubt_moment`    | workDays≥60, day≥45, 90天冷却   | 列计划/打电话回家/逃避   | 损失厌恶（逃避有心情惩罚）         |
| `workplace_opportunity`  | workDays≥30, day≥25, 60天冷却   | 接名片/询问详情/婉拒     | 社会认同（被"看见"的满足感）       |

## 设计意图

- **填补情感空白**：现有事件侧重随机遭遇和生存压力，缺少职业相关的正向情感事件
- **激励长期职业**：通过技能突破、工友感情、职场机遇等事件，让深耕同一职业有叙事回报
- **全剧本通用**：所有条件基于 `workDays`/`actionFreq`/`totalEarned` 等通用字段，不依赖特定剧本或职业路径

## 注意事项

- 每个事件都有冷却期（30-90天），避免重复触发导致疲劳
- 每个选项都有独立的叙事文本，确保 apply 中的 addMessage 描述与选项一致
- 使用 `st.flags._xxx` 标记追踪触发状态，兼容旧存档无缝接入

**Why:** 从蒙特卡洛模拟和用户反馈发现，职业系统的"情感温度"不足——玩家感觉工作只是数值循环，缺乏叙事回报。

**How to apply:** 后续可在 `career_doubt_moment` 的"列计划"选项后添加链式事件（如计划执行30天后复盘），形成完整的"迷茫-计划-执行-收获"叙事弧线。
