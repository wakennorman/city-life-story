# v3.13 超大文件拆分遗留的 const/let 重复声明 Bug

## 现象（2026-07-10）

游戏进入主页面后，5个 Tab 按钮全不显示，点击无反应。浏览器控制台有 SyntaxError。

## 根因

v3.13 将 `render.js`（7,056行）拆分为三文件时，部分重复代码未清理干净：

| 声明                                    |     `render_core.js`     |      `render.js`（遗留）      |             问题              |
| --------------------------------------- | :----------------------: | :---------------------------: | :---------------------------: |
| `let currentTab`                        |         ✅ 定义          |          ❌ 重复声明          |      `let` 不可重复声明       |
| `const TAB_RENDERERS`                   |       ✅ 新5Tab版        |         ❌ 旧多Tab版          |     `const` 不可重复声明      |
| `function renderAll()`                  |            ✅            |            ❌ 重复            |           覆盖新版            |
| `function renderTabBar()`               |            ✅            |            ❌ 重复            |           覆盖新版            |
| `function switchTab()`                  |            ✅            |            ❌ 重复            |           覆盖新版            |
| `function _firstVisibleActionCardTop()` | ❌（在 render_infra.js） |            ❌ 重复            |     覆盖 render_infra.js      |
| `function renderCurrentTab()`           | ❌（在 render_infra.js） | ❌ 重复（缺 renderGoalStrip） | 覆盖 render_infra.js 更完整版 |

## 修复

从 `render.js` 删除所有重复声明和函数定义，只保留实际 Tab 渲染函数（`renderActionsTab`、`renderMapTab` 等）。

**关键原则**：文件拆分后，每个标识符只能在一个文件中定义。

- `render_core.js` → 主渲染调度 + `TAB_RENDERERS`（5Tab版，匹配HTML）
- `render_infra.js` → `renderCurrentTab` + 5个tab渲染函数（city/me/career）
- `render.js` → 实际 Tab 内容渲染函数（actionsTab/mapTab/tradeTab等）

## 如何防范

每次 `git add` 前运行全局扫描：

```bash
node -e "
const fs = require('fs'), path = require('path');
function walk(d) { const r=[]; fs.readdirSync(d,{withFileTypes:true}).forEach(e=>{
  const p=path.join(d,e.name); if(e.isDirectory()) walk(p).forEach(f=>r.push(f));
  else if(e.name.endsWith('.js')) r.push(p);
}); return r; }
const files = walk('.');
const seen = {};
files.forEach(f => {
  fs.readFileSync(f,'utf8').split('\n').forEach((l,i) => {
    const m = l.match(/^(const|let) (\w+)\s*[=;]/);
    if (m && seen[m[2]]) console.log('CONFLICT:', m[2], 'in', f, 'line', i+1, '(also in', seen[m[2]], ')');
    if (m) seen[m[2]] = f + ':' + (i+1);
  });
});
console.log('Done');
"
```

**Why:** 浏览器非 module 的 `<script>` 标签共享全局词法环境，`const`/`let` 在不同脚本中重复声明会抛 SyntaxError，导致脚本整块不执行。

**How to apply:** 文件拆分操作必须附加"重复声明清理"步骤——修改新文件后，回头检查旧文件是否仍留有原声明。
