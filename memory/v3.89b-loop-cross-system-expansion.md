## 设计意图

1. **城管执法** (`chengguan_raid_stall`)：填补城管系统与摆摊副业的联动空白，让 chengguan.heat 有叙事出口
2. **股市暴跌** (`stock_crash_panic`)：投资系统首次获得"市场情绪"叙事事件，制造"割肉vs坚守"的经典投资抉择
3. **父母生病** (`parent_sickness_call`)：家庭系统与经济压力联动，体现"尽孝vs生存"的真实困境
4. **慢性病爆发** (`chronic_illness_onset`)：illnesses数组与长期低健康联动，体现"积劳成疾"的真实感
5. **网红黑粉** (`internet_troll_backlash`)：fame系统与道德值极端联动——高道德玩家选择一笑置之，低道德玩家可能举报封号
