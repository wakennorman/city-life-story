# 全系统优化 R17 — 域F UI 属性值数字溢出修复

## 用户反馈

"6个属性值后面的数字漂移出显示外了，这是为了和下面的状态值做对齐所以这样吗？"

## 根因分析

手机端状态条第1行(6属性: 体质/智力/敏捷/心智/魅力/道德)使用 `mss-cell-no-track` 类，
单元格内只有 `[icon][label][value]` 三元素，无 track bar 居中缓冲。
由于 `mss-label` 和 `mss-val` 都有 `flex-shrink: 0`，在窄屏上内容超出单元格宽度，
数值被推到右边界被 `overflow: hidden` 裁剪。

第2行(5需求: 饥饿/疲劳/卫生/心情/健康)使用 `mss-cell-has-track`，
track bar 在 label 和 value 之间起 `flex: 1` 缓冲作用，数值自然右对齐，无溢出。

**不是有意对齐**，而是缺少 track bar 导致的布局崩坏。

## 修复内容

| 文件 | 改动 |
|---|---|
| `style.css` | 双层 `@media (max-width: 768px)` 各加 `.mss-cell-no-track .mss-label { flex: 1; min-width: 0; }` |

## 修复历程

1. **一次修复**：`.mss-cell-no-track { justify-content: space-between; }` — 但space-between将3个flex子项(icon/label/value)独立分布，label被推到中间，数值仍可能溢出
2. **二次修复**：改为 `.mss-cell-no-track .mss-label { flex: 1; }` — label像状态行track bar一样吃剩余空间，value自然推到右边缘

## 效果

属性行label与状态行track bar同理，吃剩余空间把value推到右边缘，视觉一致。
