## v3.60 循环产出

### 修复：15个options→choices P0 Bug

`cross_system_events.js` 中15个事件使用 `options` 字段而非 `choices`。
`events_core.js` 只读 `choices`，导致这些事件触发后弹窗无按钮，完全不可交互。

自洽修复标注：在修复处添加了 `// [自洽修复] options→choices` 注释。

### 新增：3个联动事件（v3.60）

1. **skill_synergy_restaurant_offer** — 多重技能协同
   - 条件：cooking≥20 + sales≥10 + day≥30
   - 填补"多技能组合门槛"叙事空白
   - 设计心理学：禀赋效应（技能积累回报）

2. **bank_vip_treatment** — 银行位置深度事件
   - 条件：bankBalance≥5000 + day≥20
   - 填补银行位置仅有 bank_promo 的空白
   - 设计心理学：社会比较（VIP待遇）

3. **regular_customer_discount** — 熟客经济
   - 条件：actionFreq累计交易≥10 + day≥15
   - 填补 actionFreq 从未用于叙事的空白
   - 设计心理学：禀赋效应（熟客认同）
