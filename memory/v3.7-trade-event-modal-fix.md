## v3.7 修复要点

### 交易Tab undefined 修复

- **根因**：`renderTradeTab()` 中 `var skillTag` 声明在模板字符串之后，JS hoisting 导致值为 `undefined`
- **修复**：将 `skillTag` 及其依赖提前到 headerDiv 创建之前
- **教训**：`var` 声明在全函数作用域提升，使用前必须赋值。ESLint `no-use-before-define` 规则可预防

### 卖出好时机单一修复

- **根因**：`CATEGORY_NAMES_TRADE` / `getFestivalCategoryName` 只覆盖 daily/food/luxury/clothing/electronics/scrap 6 个分类，缺少 books/flowers/medicine/stationery
- **根因**：`SEASONAL_PRICE_MODS` 混入 goodId 级 key（"water"/"drinks"），且只覆盖 4-5 个分类
- **修复**：映射表补齐 10 分类；SEASONAL_PRICE_MODS 重构为全品类覆盖、每季 3-4 个品类有显著波动

### 单一路径优化

- **新增** `getBestTradeRoutes()` 实时计算所有商品×地点组合的最佳路线，显示 Top 3
- **新增** 8 条市场事件：书籍热/花市/流感/基建/快递/文具/药品/服装清仓
- **设计理念**：不破坏核心差价（批发→商业区），但通过季节波动和市场事件制造更多可选项

### 移动端弹窗居中

- **根因**：CSS 媒体查询 `.modal-overlay` 用 `align-items: flex-start`
- **修复**：`align-items: center`

### 暴雨送货事件语境

- **根因**：随机事件中「蹚水送外卖」选项的 apply 消息暗示玩家是配送员
- **修复**：叙事改为「蹚水跑腿」「帮人送东西」

### 自查清单

- [ ] 新增分类时必须同步更新 `CATEGORY_NAMES_TRADE`（render.js）和 `getFestivalCategoryName`（festivals.js）
- [ ] `var` 变量在模板字符串中使用前必须赋值
- [ ] 随机事件的动作描述不应暗示玩家职业
