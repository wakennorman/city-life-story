# v3.85 事业Tab全面打磨（2026-07-11）

**触发**：用户 /loop deep-research 指令，全面优化事业Tab下属性训练/求职/副业/各模块

## 变更详情

### 🏋️ 属性训练重平衡（参考《完美人生》高属性递减收益）

| 变更项   | 原值                             | 新值                       | 原因                       |
| -------- | -------------------------------- | -------------------------- | -------------------------- |
| 健身房   | ¥50+30/次, gain[1,3]             | ¥40+25/次, gain[2,4]       | 付费训练应有更好回报       |
| 自习室   | ¥60+40/次, gain[1,3]             | ¥30+20/次, gain[1,3]       | 学习成本降低，鼓励知识投资 |
| **晨跑** | **¥40+25/次, gain[1,3]**         | **🆓免费, gain[1,2], AP4** | 跑步不应该花钱！改为免费   |
| **冥想** | **¥70+50/次, gain[1,2], 无地点** | **🆓免费, gain[1,2], AP3** | 冥想不应该花钱，随处可做   |
| 形象打理 | ¥100+80/次                       | ¥80+60/次                  | 略微降低                   |
| 整容手术 | ¥2000+1500/次                    | 不变                       | 高风险高投入不变           |

**核心机制**：

- **递减收益**：属性≥70时收益×0.8，≥80时×0.6，≥90时×0.4（参考《完美人生》高属性难提升）
- **AP费用统一**：体力训练(6AP) > 智力(6AP) > 敏捷(4AP) > 魅力(4AP) > 冥想(3AP)
- **地点锚定**：所有训练（除冥想）需要在对的地点进行
- **UI增强**：显示AP消耗+收益范围+地点要求

### 🐛 关键Bug修复：showModal按钮参数

**问题**：`__doTrain()` 调用 `showModal()` 时传 `{label, primary, onClick}` 但 `showModal` 期望 `{text, cls, callback}` → `btn.textContent = btn.text` 为 `undefined` → 弹窗按钮显示为空白绿框

**修复**：改用 `{text: "前往...", cls: "btn-primary", callback: fn}` 格式，按钮文字正常显示

### 💼 求职UI框线增强

- **新增 `.card` CSS类**：白色底 + `border: 1px solid var(--border)` + **左侧3px彩色accent条**
- **卡片hover效果**：鼠标悬停边框变accent色
- **推荐路径**：可投递→绿色左边框，条件不足→浅灰左边框
- **职业路径网格**：`repeat(auto-fill, minmax(200px, 1fr))` 自适应
- **移动端适配**：窄屏自动切单列

### 🔄 副业UI排列规整

- **重新CSS类**：`.hustle-grid` + `.hustle-card` 替代 flex-wrap
- **CSS Grid布局**：`repeat(auto-fill, minmax(240px, 1fr))` 等宽自适应
- **卡片结构**：icon+名称 → 描述 → 元数据 → 条件 → 按钮
- **可用性标识**：可用→彩色左边框，不可用→灰色左边框
- **移动端适配**：480px以下切单列
