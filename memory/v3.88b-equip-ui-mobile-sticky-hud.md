# v3.88b 装备栏 UI 修正 + 手机端固定 HUD 修复

**日期**：2026-07-11

## 改动内容

### Bug 根因修复

v3.88 的 HUD 代码改到了 `render.js` 的 `renderCurrentTab_legacy` 函数，但该函数是**死代码，从未被调用**。实际渲染路径是 `render_infra.js` 的 `renderCurrentTab`。v3.88b 将 HUD 逻辑移到正确位置。

### 手机端固定 HUD（position: sticky）

- `#mobile-hud` 作为 `#content-area` 首个子节点
- `position: sticky; top: 0; z-index: 5; background: var(--bg-primary);`
- 时间槽、位置条、状态条 3 个栏位始终固定在顶部
- 用户滑动内容时，AP/状态/属性始终可见（像底部事件记录栏一样固定）

### 装备栏 UI 修正

- 提示文字修正：删除"电子→科技园/书本→大学城"（slot: null 的道具不应出现在装备栏）
- 新文案按实际装备槽 buyLocations：⛑️头部/🧤手部→批发市场/工地 | 👕身体/👟脚部→批发市场/商业区 | 📿配件→批发市场/商业区
- 空槽点击弹出导航弹窗，列出该槽全部可购装备 + 一键导航

## 影响文件

- `render_infra.js`（+18/-10）：renderCurrentTab 加入 mobile HUD 逻辑
- `render.js`（-58/-30）：还原死代码到原始状态
- `style.css`（+6）：#mobile-hud 改用 position: sticky
- `dist/index.html`：重建

## 教训

- 修改前必须确认目标函数是否被实际调用
- `render_infra.js` 和 `render.js` 都定义了 `renderCurrentTab_legacy` / `renderCurrentTab`，需检查脚本加载顺序和实际调用点
- 文件拆分后，修改函数前先 grep 确认函数定义位置 + 调用位置
