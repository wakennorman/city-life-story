# v3.88c 手机端 HUD 修复 + 装备栏 UI 修正

**日期**：2026-07-11

## 改动内容

### 手机端固定 HUD（flex-shrink:0 兄弟节点）

`#mobile-hud` 作为 `#content-area` 的兄弟节点（与 `#tab-bar` 同级）放在 `#main` flex 容器中。利用 `flex-shrink:0` 固定顶部，只有 `#content-area` 滚动。时间槽+位置条+状态条始终可见。

### 装备栏 UI 修正

- 提示文字修正：删除"电子→科技园/书本→大学城"（slot: null 的道具不应出现在装备栏）
- 新文案按实际装备槽 buyLocations：⛑️头部/🧤手部→批发市场/工地 | 👕身体/👟脚部→批发市场/商业区 | 📿配件→批发市场/商业区
- 空槽点击弹出导航弹窗，列出该槽全部可购装备 + 一键导航

### 教训（三连！）

1. **改文件前必须确认目标函数是否被实际调用**：v3.88 改到 `render.js` 的 `renderCurrentTab_legacy`（死代码），浪费一次 commit
2. **position:sticky 在 flex 子节点+overflow:auto 容器中不可靠**：v3.88b 改用 sticky 导致 HUD 不显示。最终方案与 `#tab-bar`/`#message-log` 相同——flex-shrink:0 兄弟节点
3. **文件拆分陷阱**：`render_infra.js` 和 `render.js` 有同名函数族，先 `grep` 确认函数定义位置 + 调用位置再动手
