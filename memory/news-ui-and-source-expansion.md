# 世界新闻 UI 配色改造 + 全系统影响扩展 + 新闻源替换

**2026-07-03 实装（第43-44轮）** — 世界新闻系统的两轮迭代：UI从暗色科技→温暖报刊风 + 新闻源从社会综合→专业财经。

## 第43轮：UI配色改造 + 全系统影响扩展

### 问题

- 新闻弹窗使用 GitHub Dark 风格，与游戏奶油白+鼠尾草绿基调割裂
- 开局新闻只设 `_worldParams.sectorHeat`，未进 `activeNews`，导致 `news_investment_bridge` 等全链路无法读取

### UI 改造：暗色科技 → 温暖报刊风

| 区域     | 旧                  | 新                            |
| -------- | ------------------- | ----------------------------- |
| 遮罩层   | `rgba(0,0,0,0.92)`  | `rgba(245,241,232,0.93)` 暖白 |
| 主面板   | `#0d1117` 黑底      | `#ffffff` 白底                |
| 标题栏   | 深色渐变+红色底边   | 奶油渐变+绿色accent底边       |
| 新闻条目 | `#161b22` 深色卡    | `var(--bg-card)` 白卡+暖边框  |
| 标签     | 蓝色 `#58a6ff` 大写 | 绿色accent小写                |
| 按钮     | 蓝色渐变            | 绿色accent一致按钮            |
| 阴影     | 蓝色辉光            | 暖灰自然阴影                  |

**设计参考**：《大多数》开场报纸 / Papers Please 公报 / 经济学人 / Notion Light

### 全系统影响扩展（关键改动）

1. **预存新闻新增 `investmentEffect`**：20+条预存新闻添加 `{ industry, mul }` / `{ symbols, mul }`，利好 1.06~~1.22，利空 0.85~~0.95
2. **实时新闻分类引擎新增 `generateInvestmentEffectFromTag`**：覆盖 20 个分类标签
3. **`applyNewsAndEnter` 注入 `state.activeNews`**：`intro_`前缀 + `duration: 365` 整局有效 + `_isIntroNews` 标记

**影响链路**：

```
开局新闻 → state.activeNews → tickInvestmentDaily → 股票/BTC/房产价格
                           → getNewsJobBoost → 工作收入加成
                           → applyNewsEventWeights → 事件权重
                           → applyNewsPriceSentiment → 商品价格漂移
                           → applyNewsLongTail → 长尾效应
```

## 第44轮：新闻源替换 + 分类引擎强化 + 经济扩充

### 问题

实时新闻被"宏大叙事"类主流媒体源主导，大量社会综合类新闻，经济/金融类极少。

### A1: RSS 源替换

| 旧源（已移除）   | 新源（已添加） |
| ---------------- | -------------- |
| 新浪新闻（社会） | **新浪财经**   |
| 网易新闻（社会） | **36氪**       |
| 人民网时政       | **华尔街见闻** |
| 保留：新浪科技   | —              |

### A2: 分类引擎强化

- **经济规则扩展**：新增 PPI/PMI/准备金率/流动性/货币/财政/赤字/国债/地方债/汇率/美联储/宏观经济/景气/衰退/复苏 等 20+ 关键词
- **新增「金融」规则**：股市/A股/港股/美股/基金/ETF/理财/股票/指数/北向资金/牛市/熊市/涨停/跌停/IPO/可转债 等 30+ 关键词
- **新增「消费」规则**：零售/电商/网购/促销/营业额/门店/客流/外卖/餐饮/旅游 等 20+ 关键词
- **社会规则缩窄**：去掉宽泛民生/教育/躺平等词，保留养老/社保/生育/户籍

### A3: 5 级智能兜底

旧逻辑：不匹配→一刀切"社会综合"
新逻辑：含数字+百分比→经济 → 含金额→经济 → 含企业市场→产业 → 含城市基建→城市发展 → 真正无匹配→综合

### A4: 预存经济新闻扩充

6→14条（出口订单激增/一级市场募资寒冬/消费降级/国债收益率/房企债务/金价新高/物流竞争/半导体周期/券商扩招/快递用工/医疗人才），就业 6→9条
