# 版本一致性铁律 — ✅ 问题已解决

> **教训：** 城市浮生记项目曾有两个版本，多次会话因改错版本导致工作白费。
> **解决方案：** 2026-06-21 已将全部独特内容从旧版迁移到活跃版，旧版已清理。

**Why:** 项目存在两个游戏版本（根 `src/` 遗留版 和 `city-life-story/src/` 活跃版），Claude Code 有多个配置目录，导致模型/窗口切换时容易操作到错误版本。累计有 3-4 个独立会话因此损失数千行工作量。

**How to apply:** 尽管问题已解决，仍应遵循以下规则以防类似情况再次发生。

---

## 单一版本规则

**当前项目只有一个活跃版本：** `city-life-story/src/`

所有开发工作直接在 `city-life-story/src/` 下进行。根 `src/` 已清理。

---

## 预防性检查

如果将来再有类似的多版本项目，请遵循：

1. **编辑前先 `git status`** — 确认自己在正确的仓库
2. **文件路径必须包含 `city-life-story/` 前缀**
3. **新文件必须放在 active 版本的目录下**
4. **同步修改所有相关文件**（`index.html` 加载、`DEVELOPMENT.md` 记录）
