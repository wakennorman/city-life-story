# v3.1 NG+ 继承增强 — 记忆文件

## 触发条件

玩家游戏结束 → 重新开始 → 弹出「继承上局遗产」弹窗 → 展示全部继承数据

## 核心改进

### 1. 继承摘要弹窗展示全部字段

**之前**：只展示徽章/现金/关系数/物品数/梦想/技能树（6 类）
**之后**：新增 35 岁路径 / 前世业力 / 老熟人（9 类）

| 新增模块     | 数据源                       | 展示内容                                                   |
| ------------ | ---------------------------- | ---------------------------------------------------------- |
| 📋 35 岁路径 | `inheritCrisisPath(state)`   | 路径标签 + 属性加成 + 特殊加成说明                         |
| ⚖️ 前世业力  | `inheritMoralScore(state)`   | 善恶净值 + 标签 + 善行/恶行次数 + NPC好感偏移 + 道德事件率 |
| 👥 老熟人    | `inheritPeakAffinity(state)` | 每个 NPC 的巅峰好感 chip                                   |

### 2. 35 岁路径继承增强

| 路径     | 原加成 | 新加成            | 消费点               |
| -------- | ------ | ----------------- | -------------------- |
| 再卷职场 | 心智+3 | 晋升+3%, 月薪+5%  | promo.js P9→P10      |
| 备考公   | 智力+3 | 考试+10%, 公职+3% | 待接入 career_dev.js |
| 摆烂     | 心情+5 | 恢复+10%, 压力-3  | needs.js 日恢复      |

### 3. 道德分 → 业力系统

| 原效果      | 新效果                              | 消费点               |
| ----------- | ----------------------------------- | -------------------- |
| 幸运(-3~+5) | NPC好感(-8~+8), 道德事件(-15%~+15%) | main.js 道德事件判定 |

### 4. 加成消费断链修复

`inheritanceBonuses` 中 `promoChance`/`moralEventRate`/`recoveryRate` 等字段此前被 SET 但从未被 CONSUMED。本轮修复 3 处：

- `promoChance` → `phase2/promo.js::checkPromotion` P9→P10
- `moralEventRate` → `main.js` 每日道德事件判定
- `recoveryRate` → `phase1/needs.js::tickHealthStatus`
