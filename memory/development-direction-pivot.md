# 战略转向:数据层优化 → 三大开发方向

> 确立时间: 2026-07-27 | 触发: R429完成后用户确认

## 背景
经过429轮数据层优化(R258-R429),全8域A类缺陷净尽,318+联动事件覆盖全部56种域间配对。数据层优化边际收益接近零,需要转向。

## 三大核心方向(后续"/loop"自动进入)

### 方向1: 本地F5玩法测试
- **目标**: 浏览器本地运行游戏,发现真实体验问题
- **方法**: `cd city-life-story && python build.py && start dist/index.html`
- **关注**: 运行时错误/交互断裂/体验不流畅/剧本flag失效
- **产出**: 体验问题清单 → 优先级排序 → 修复

### 方向2: MC蒙特卡洛平衡验证
- **目标**: 用统计方法验证游戏数值平衡
- **方法**: `node tools/monte_carlo_runner.js` 或内联 `mc.run()`
- **关注**: 各策略存活率/资产区间/事件触发率/通胀失衡
- **产出**: 平衡调参建议 → 数值修正

### 方向3: 新内容开发
- **目标**: 扩充游戏可玩性内容
- **方法**: 新增NPC/地点/事件/职业/剧本/装备/食材/疾病
- **关注**: 风格一致性/数据自洽/联动注册/全剧本适配
- **产出**: 新内容 → 联动事件 → 百科自动注册

## 执行规则
- 每次"/loop"自动选择当前最紧迫的方向
- 优先级: F5体验问题 > MC平衡异常 > 新内容扩充
- 发现A类缺陷立即修,发现联动机会立即做
- 每轮必须 git commit + push
