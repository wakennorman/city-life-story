**存档快照** — ✅ 已完成

**实现内容：**

1. `createSnapshot(state)` — 提取关键状态字段（街头/职场阶段属性、需求、健康、财富等）
2. `generateMemoryText(snapshot)` — 生成"那时候你..."回忆文案
3. `getLoadMemoryText(slot)` — 读取存档时获取回忆文案
4. `updateSlotSnapshot(slot, state)` — 更新槽位快照信息

**快照记录字段：**

- 街头阶段：四维属性、需求值、健康、住房等级、债务
- 职场阶段：职级、发量、尊严、向上管理、KPI、能力、风险、人缘、绩效次数、团队人数
- 通用：现金、总收入、生病/受伤状态、情感状态

**回忆文案示例：**

- "那时候你第120天，21岁，身体还算硬朗，心智清醒，肚子咕咕叫，疲惫不堪，住在单间，欠着¥3000，攒了¥8000。"
- "那时候你第450天，25岁，已经是P7了，发量还够用，尊严所剩无几，连续2次绩效C，带着5人的团队，手握¥12.5万，压力很大。"
