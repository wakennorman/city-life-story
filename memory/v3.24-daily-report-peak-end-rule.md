## 设计心理学锚点

### 峰终定律 (Peak-End Rule, Kahneman 2002)

- **🏆 今日高光**: 让每一天都有一个可记忆的"峰值体验"
  - 单笔收入峰值（¥100/¥500两档）+ 天数里程碑（D7/30/100/365）+ 累计收入里程碑（¥1k/5k/10k/100k）
  - 损失厌恶触发：健康下滑/债务预警
  - 平凡日温暖收尾：「活着就是赢了」
- **🔮 明日展望**: 在终点处埋下期待（留存钩子）

### 留存机制

- 天气预报调用 `getForecastHTML()` 桥接已有气象预报系统
- 状态最低需求建议（饿/累/病/脏 — 损失厌恶触发）
- 天数情感锚点（🌱→🌿→🌳→🌲）
- D1/D30/D100 情感收尾句

### 设计参考

- Stardew Valley：每日天气播报
- Papers Please：日报总结系统
- 《大多数》：日记式收尾
- 峰终定律：Kahneman 2002 Nobel Prize

- `generateTomorrowPreviewHTML(state)` — 生成明日展望区块
