# v3.38 状态积累爆发事件

## 新增事件

| 事件id                      | 触发条件                               | 选项                                   | 设计心理学                               |
| --------------------------- | -------------------------------------- | -------------------------------------- | ---------------------------------------- |
| `low_mood_crisis_encounter` | lowHappinessStreak≥3, day≥10, 30天冷却 | 收花(心情+15)/婉拒(心情-2)             | 峰终定律（低谷中陌生人的善意打破负循环） |
| `junk_food_body_warning`    | junkFoodMeals≥10, day≥15, 60天冷却     | 买药(健康+8)/硬扛(健康-5)/熬粥(健康+5) | 损失厌恶（硬扛有惩罚，推动健康饮食）     |
| `night_owl_encounter`       | lateNightActions≥5, day≥20, 90天冷却   | 聊天(社交+)/赶路/请夜宵(魅力+2)        | 社会比较（深夜同类人缓解孤独）           |

## 覆盖的空白

`_habits` 追踪的 6 个指标：

- ✅ `lowHungerStreak` → 已有 `starvation_body_alarm` (v3.21)
- ✅ `highFatigueStreak` → 已有 `overwork_body_crash` (v3.20)
- ✅ `lowHappinessStreak` → **new** `low_mood_crisis_encounter`
- ✅ `junkFoodMeals` → **new** `junk_food_body_warning`
- ✅ `lateNightActions` → **new** `night_owl_encounter`
- ⏭️ `stomach_inflammationCount` → 已有 illness 系统覆盖，无需事件

## 设计原则

1. **每种跟踪状态都有叙事回响**：玩家每次看到状态变化，都会潜意识知道"这个状态低到一定程度会有故事发生"
2. **冷却期差异化**：心情事件30天（高频）、垃圾食品60天（中频）、深夜行动90天（低频）
3. **全剧本适配**：所有条件基于通用字段，不依赖特定剧本
4. **正向引导**：每个事件的最优选项提供正向鼓励，次优选项也有叙事价值

**Why:** 系统已有 `_habits` 追踪字段但只被 illness 系统消费，缺少叙事层反馈。

**How to apply:** 后续可增加 chainEvent 后续，例如 `night_owl_encounter` 认识的人3天后再次偶遇、`junk_food_body_warning` 买药后7天的健康改善跟踪。
