**v3.88g 经济平衡分析** — 2026-07-11

## 蒙特卡洛模拟结果 (5000次×9种组合×1000天)

### 关键发现

1. **财富税触发率100%**：所有组合在1000天内均触发精英税。
   - Casual: 中位数¥2.7M → 精英税, 总征税¥1.67B
   - Normal: 中位数¥2.6M → 精英税, 总征税¥2.29B
   - Hard: 中位数¥2.2M → 精英税, 总征税¥2.60B

2. **开局资金差异消失**：¥5K/¥10K/¥30K开局最终资产几乎相同。
   - Casual ¥5K vs ¥30K: 均值差仅¥16K (0.6%)
   - 说明财富税对早期差异的抹平效应极强

3. **难度差异显著**：
   - Hard比Casual最终资产低约18-19%
   - Hard总征税比Casual高56%

4. **模拟局限**：simulation中effectiveCash替代cash造成复利税损，与实际游戏不符。实际游戏中wealth_tax仅从cash扣除，不影响bankBalance。

## 三层财富税系统评估

### 系统1: economy_v3.1.js — 每日累进财富税

- 阈值: ¥20万(入门) → ¥50万(中产) → ¥200万(精英) → ¥1000万(富豪)
- 日税率: 0.03% → 0.05% → 0.08% → 0.12%
- 难度乘数: casual 0.7x, normal 1.0x, hard 1.4x
- **评估**: 累进合理，富豪税0.12%/日=年化43.8%，对超高资产玩家有显著压制

### 系统2: review_improvements.js — 周期性中产税事件

- 触发: 每7-14天, 基础35%(难度0.2/0.35/0.5/0.7)
- 门槛: 总资产≥¥20万
- 7个事件池: 房产核查(¥30万起)、学区赞助(¥25万)、老同学借款(¥20万)、远房亲戚(¥50万)、物业费(¥40万)、税务健康检查(¥80万)、慈善晚宴(¥100万)
- 单次支出: 总财富的0.8%-2.5%，上限¥8万-¥5万
- **评估**: 事件设计贴合中国本土情境，成本曲线合理

### 系统3: cross_system_events.js — 叙事型税务事件

- 触发: day>300, 现金+存款>¥50万, 概率4%
- 3个选择: 主动申报(8%)、请会计师(4-6%)、无视(无即时成本)
- **评估**: 叙事丰富但触发门槛较高(day>300)，实际影响有限

### 综合评估

| 指标       | 评分       | 说明                                   |
| ---------- | ---------- | -------------------------------------- |
| 累进性     | ⭐⭐⭐⭐   | 四级阈值覆盖广，边际税率递增           |
| 难度区分   | ⭐⭐⭐⭐   | Hard比Casual税负高56%                  |
| 本土化     | ⭐⭐⭐⭐⭐ | 中产税事件极具中国特色                 |
| 过度惩罚   | ⭐⭐⭐     | 所有玩家最终都触及精英税，缺乏"安全港" |
| 策略多样性 | ⭐⭐⭐     | 存款vs现金的税务规划空间有限           |

### 建议

1. **考虑增加"免税额度"**：类似现实个税起征点，总资产<¥100万的部分免税
2. **房产投资回报偏低**：模拟显示房产投资在45天周期内收益不稳定
3. **创业退出机制过于乐观**：模拟中创业收益远高于其他投资，可能导致策略单一化
