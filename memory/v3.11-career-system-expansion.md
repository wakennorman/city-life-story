# v3.11 职业系统深度扩展（2026-07-03）

## 新增职业路径

| 路径        | ID                 | 等级 | 顶级薪资 | 证书加成       |
| ----------- | ------------------ | ---- | -------- | -------------- |
| 👨‍⚕️ 医师     | doctor             | 5级  | ¥38,000  | 医师资格证+20% |
| 🏢 事业单位 | public_institution | 5级  | ¥23,000  | 职称证+10%     |

## 跨系统联动

- **医师路径↔medical.js**：`getCareerMedicalDiscount(state)` → 治疗费用折扣5%-35%
- **医师路径↔健康**：medicine技能≥20时30%概率每日健康回复+0.5
- **护理路径↔medical.js**：治疗折扣3%-18%
- **公务员路径↔legal.js**：法律服务折扣5%-25%
- **事业单位路径↔legal.js**：法律服务折扣3%-28%
- **医疗路径↔疾病**：护理人员每日20%概率健康回复+0.3

## 雇佣机制

- **面试**：`enhancedApplyCareerJob()` — 基于属性/技能计算成功率30%-95%
- **试用期**：前90天薪资80%，每30天提示剩余天数
- **解雇**：连续30天业绩<20 → 自动解雇（含历史记录）

## 新增证书

- `medical_license` — 医师资格证（执业医师考试通过或住院医师满365天自动获取）
- `professional_title_cert` — 事业单位职称证

## 总数据

- CAREER_PATHS：10路径 × 42职位（原8×32）
- 证书加成：20条规则（原12条）
- 职业专属事件：45个（原35个）
- 影响文件：career_dev.js, career_path_events.js, medical.js, legal.js, daily_pipeline.js
