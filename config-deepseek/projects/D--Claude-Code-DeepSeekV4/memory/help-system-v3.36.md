游戏帮助弹窗（`showHelpModal` 在 `modal.js`）全面重写，反映当前游戏真实全貌。

**核心改动**:

- 旧帮助专注于"街头生存→职场晋升"两阶段，忽略7剧本/沙盒/世界参数等大量系统
- 新帮助6个模块：🎭剧本模式 → 🗺️核心生存循环 → 🔬约定式自动归类 → 📖游戏百科指引 → 🧠深度系统一览 → 💡新手必备

**约定式自动归类（CoC）** 在帮助中的呈现：

- 新增即生效：新地点/工作/NPC/商品/技能/证书 → 自动出现在百科+导航
- 数据声明即可：加一条 location 数据，百科条目+详情按钮全自动生成
- 事件触发数据化：声明 conditions/apply 字段，系统自动注册到触发槽
- 行动自动归类：行动加 category 字段即自动分组显示

**设计原则**:

- 所有数字精确反映当前游戏状态（42职位/10路径/350+事件/4档难度/7剧本）
- 全剧本适配：帮助内容对所有7个剧本+沙盒通用
- 百科优先：引导玩家按 Tab → 百科 查阅详情
