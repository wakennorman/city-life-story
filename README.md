# 城市浮生记 (City Life Story)

> 一款中国都市生活模拟游戏，体验从底层打拼到财务自由的完整人生轨迹。

## 项目状态

- **当前版本：** v3.1
- **v3.0 审查评分：** 7.0/10 → **v3.1 评分：** 7.6/10
- **蒙特卡洛验证：** 1000 天 × 45,000 次模拟，通过

## v3.1 改进

| 问题          | 改进                          | 验证结果                             |
| ------------- | ----------------------------- | ------------------------------------ |
| B1 指数膨胀   | 连续盈利衰减 + 市场饱和度惩罚 | P99 资产 ¥340万，无极端膨胀          |
| B2 村长债无效 | 六级动态利率 0.20%→1.00%/日   | 老玩家 ¥3M+ 享受 1%/日               |
| B4 财富税过低 | 四级累进税 0.03%~0.12%/日     | 100% 触发率                          |
| B5 难度单一   | 收入+机会+晋升三维度          | 休闲¥273万 > 标准¥261万 > 困难¥223万 |
